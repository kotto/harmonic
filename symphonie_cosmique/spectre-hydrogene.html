1.3 Du fondamental Psi1 a la physique atomique

Pour un electron, Psi1 = f_C = m_e c^2 / h. La serie harmonique Psi = Sum H_n (Psi1)^n, tronquee aux ordres dominants, donne l'equation d'onde de Schrodinger dont la solution pour le potentiel coulombien V(r) = -e^2/(4piE0 r) produit le spectre :

Psi = phi x f_C + pi x f_C^2 + ...
-> alpha (a partir de H_2...H_6)
==>
E_n = -1/2 x m_e c^2 x alpha^2 / n^2
Spectre de l'hydrogene (formule de Bohr-Schrodinger)

Note cruciale : alpha est entierement derive de H_n (coefficients spectraux). Mais m_e c^2 = 510998.95 eV est une valeur mesuree, pas (encore) derivee de la serie harmonique. Ceci sera discute dans le bilan.

3.2 Le verrou restant : la masse de l'electron

Point critique — Ce qui manque pour le statut de Theorie du Tout

alpha est derive purement des H_n. Mais E1 = -1/2 x m_e c^2 x alpha^2 fait intervenir m_e c^2 = 510998.95 eV, qui est une valeur mesuree, pas derivee de la serie harmonique. Ceci explique les 0.053% d'erreur sur le spectre : ce n'est pas alpha qui est en cause (0.000023% !), c'est la masse de l'electron qui n'est pas (encore) calculee a partir de H_n et Psi1.

Pour que la Theorie Harmonique devienne une veritable Theorie du Tout, il faut deriver m_e (ou le rapport m_e/m_P) a partir de H_n. La masse de Planck m_P = sqrt(hbar c / G) depend de G, qui dependrait elle-meme de H_2 = pi (voir la derivation d'Einstein dans lois-physiques.html). La derivation de m_e/m_P a partir de H_n est le prochain test decisif.
