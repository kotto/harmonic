                         DÉMARRAGE RAPIDE
================================================================================

1. Vérifier l'intégrité:
   $ python cdn/verify_services.py

2. Lancer tous les services:
   $ python cdn/services/launch_all_services.py

3. Accéder au CDN Gateway:
   - URL: http://localhost:9000
   - Dashboard: http://localhost:9000/dashboard
   - API Docs: http://localhost:9000/docs

4. Tester les services:
   $ curl http://localhost:9010/          # TV 4K
   $ curl http://localhost:9011/          # TV 8K
   $ curl http://localhost:9013/countries # Mobile Africa
   $ curl http://localhost:9019/stations  # Radio
