Code Integrity
Reverse engineering player
Le player ne contient aucun algorithme de compression ni de format HCS. Obfuscation JS + identifier mangling. Même en le lisant entièrement, aucune propriété intellectuelle n'est exposée.
Interception réseau (MITM)
TLS 1.3 + certificate pinning (hash hardcodé). Frames AES-GCM-256 avec IV unique. HMAC-SHA256 sur chaque payload. Replay impossible (nonce + timestamp validés).
Extraction depuis canvas
toDataURL() et toBlob() interceptés. Chaque frame porte un watermark LSB encodant l'ID de session, le timestamp et l'IP. Toute extraction est traçable jusqu'à l'utilisateur.
Vol de token JWT
JWT lié au fingerprint navigateur (canvas FP + UA hash + timezone + GPU). Expiration 1h. Refresh token via re-authentification ECDH. Révocation instantanée côté serveur.
Accès non autorisé aux fichiers
Fichiers HCS stockés chiffrés AES-256 sur S3. Clés sur AWS KMS dédié, jamais sur le serveur principal. Fichiers jamais servis bruts : déchiffrés + re-chiffrés par session à la volée.
Décompilation du Worker
Le Web Worker ne contient que le déchiffrement AES-GCM (Web Crypto API native). La clé dérivée n'est jamais accessible depuis le thread principal. Même en inspectant le Worker, aucun algo propriétaire.
