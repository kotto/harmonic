📡 Endpoints API

POST /v1/ask          → Question + réponse + trace spectrale
POST /v1/verify       → Vérifier une affirmation contre l'hologramme
GET  /v1/facts/{id}   → Consulter un fait source
POST /v1/learn        → Apprendre un nouveau fait (O(1), instantané)
GET  /v1/stats        → Statistiques du moteur (requêtes, confiance, domaines)
