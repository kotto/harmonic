Comment ça marche

1️⃣   LLM (GPT-4, Claude) génère une réponse
         ↓
2️⃣   Harmonic API vérifie chaque affirmation
         ↓    contre l'hologramme déterministe
3️⃣   Réponse annotée :
         ✅ VÉRIFIÉ — présent dans l'hologramme
         ⚠️ INCERTAIN — interférence trop faible
         ❌ CONTREDIT — fait contradictoire trouvé
         ↓
4️⃣   Si ⚠️ ou ❌ → fallback sur réponse harmonique
