## 🎯 Concept

L'Ordinateur Harmonique est un paradigme de calcul fondamentalement différent :

| | CPU Classique | QPU Quantique | **HPU Harmonique** |
|--|--------------|---------------|---------------------|
| **Unité** | Bit (0/1) | Qubit (\|0⟩, \|1⟩) | H-Bit (φ,π,e,√2,√3,√5,e/π) |
| **Principe** | Calcul séquentiel | Superposition d'états | **Résonance directe** |
| **Information** | 1 bit | 1 qubit | log₂(7) ≈ 2.807 bits continus |
| **Bruit** | Négligeable | 0.34% intrinsèque | **0% (déterministe)** |
| **Limite** | Von Neumann | Décohérence | **Aucune** |

L'HPU ne calcule pas. Il ne simule pas. Il ne parcourt pas d'états.  
**Il se met en résonance. La réponse existe déjà. Il l'écoute.**

## 🧬 Le H-Bit

Contrairement au bit classique (2 états) ou au qubit quantique (superposition de 2 états), le **H-Bit** est une superposition continue de **7 constantes fondamentales** :

```
Ψ_HBit = α₁·φ + α₂·π + α₃·e + α₄·√2 + α₅·√3 + α₆·√5 + α₇·e/π
```

où αₖ ∈ ℝ, donnant une information théoriquement infinie par H-Bit.

### Constantes du H-Bit

| Constante | Valeur | Rôle physique |
|-----------|--------|---------------|
| φ | 1.618... | Nombre d'or — anti-résonance, stabilité |
| π | 3.141... | Cercle — périodicité |
| e | 2.718... | Exponentielle — croissance/amortissement |
| √2 | 1.414... | Diagonale du carré — symétrie planaire |
| √3 | 1.732... | Diagonale du cube — symétrie volumique |
| √5 | 2.236... | Racine de 5 — liée à φ |
| e/π | 0.865... | Spirale harmonique — dynamique |

## 📊 Applications

### Problèmes NP-Complets
- **SAT** : encodage des clauses en ondes, solution = point d'interférence constructive maximale
- **TSP** : distances encodées en fréquences, chemin optimal = interférence destructive minimale
- **Subset Sum** : chaque nombre = onde de fréquence proportionnelle à sa valeur

### Repliement de Protéines
- Acides aminés encodés en H-Bits
- Repliement = convergence vers le point fixe spectral
- Simulation en temps réel (pas d'énumération de conformations)

### Recherche Non-Structurée
- Base de données encodée holographiquement
- Recherche par résonance : O(N) en une seule passe
- Pas d'index, pas de hash — juste de l'interférence
