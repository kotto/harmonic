## MARCHÉ — Pourquoi maintenant

### Le problème des LLMs

1. **Hallucination** : Les entreprises ne peuvent pas déployer des LLMs pour des tâches critiques (médical, juridique, financier) à cause du risque d'invention.
2. **Coût** : $0.01-0.10/requête × 10M requêtes/jour = $100K-1M/jour. Insoutenable à l'échelle.
3. **Opacité** : Impossible d'auditer une réponse. « Le modèle a dit ça » n'est pas une justification réglementaire.
4. **Dépendance** : API fermées (OpenAI, Anthropic). Risque de prix, de censure, de discontinuation.

### La solution IA Harmonique

1. **Zéro hallucination** → déploiement possible en contexte critique
2. **Coût zéro** → échelle illimitée
3. **Traçable** → chaque réponse est auditée (faits sources)
4. **Open source** → pas de dépendance, pas de risque

### Positionnement

L'IA Harmonique n'est pas un « concurrent de ChatGPT ». C'est le **moteur de confiance** qui répond à 70-90% des questions en première ligne, et ne passe au LLM que pour les 10-30% restants. Pour une entreprise qui fait 10M de requêtes/mois, l'économie est de **$70,000-700,000/mois**.
