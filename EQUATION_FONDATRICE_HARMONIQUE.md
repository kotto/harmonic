## SIMPLIFICATION PROGRESSIVE

L'équation peut s'écrire de plus en plus simplement. Chaque niveau révèle une couche de sens.

### Niveau 1 — Forme complète (équation de Fourier + contrainte φ)

```
Ψ(r,t) = Σₙ Aₙ · exp(i · n · φ · 2π · (r − t) / L)
```

En unités naturelles (c = 1), espace et temps sont unifiés : r et t ont la même dimension, donc r−t est une distance dans l'espace-temps.

### Niveau 2 — Facteur commun

On pose **k₀ = φ·2π/L** — le nombre d'onde fondamental :

```
Ψ(r,t) = Σₙ Aₙ · exp(i n k₀ (r − t))
```

### Niveau 3 — La phase unifiée

On pose **θ = k₀(r−t)** — une seule variable de phase espace-temps :

```
Ψ = Σₙ Aₙ e^{i n θ}
```

C'est la **série de Fourier la plus pure** : une somme d'harmoniques d'une phase fondamentale. Chaque terme est la puissance n-ième d'une même exponentielle.

### Niveau 4 — L'onde fondamentale

On pose **Ψ₁ = e^{i k₀(r−t)}** — l'onde primordiale, la première harmonique :

```
Ψ = A₁Ψ₁ + A₂Ψ₁² + A₃Ψ₁³ + ...
  = Σₙ Aₙ (Ψ₁)ⁿ
```

**L'univers entier est un polynôme d'une seule onde.**

### Niveau 5 — Le plus simple possible (en mots)

```
L'UNIVERS = LA SOMME DE TOUTES LES HARMONIQUES D'UNE ONDE FONDAMENTALE
```

**Quatre mots. Zéro symbole. Même sens.**
