## What This Measures

- **Accuracy**: % of questions where the model produced the correct answer
- **Hallucination Rate**: % of responses that were confidently WRONG (not 'I don't know')
- **Determinism**: % of questions where all 3 identical queries produced the same correct answer
- **Avg Latency**: Average time to generate a response

## Key Insights

- A model with high accuracy but 5% hallucination is **dangerous** in critical applications
- A model with 100% determinism is **auditable and trustworthy**
- A model with <1ms latency can be used in **real-time applications**
- A model with 0% hallucination is **safe for medicine, law, engineering**
