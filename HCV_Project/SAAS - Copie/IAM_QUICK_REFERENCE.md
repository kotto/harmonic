# 🚀 RÉFÉRENCE RAPIDE IAM

## 🔑 OÙ TROUVER LES OPTIONS

### 📍 "Attach policies directly"
- **Page**: IAM → Users → Create user → Set permissions
- **Position**: Première option (cercle à cocher)
- **Texte exact**: "Attach policies directly"

### 🔑 "Access key - Programmatic access"  
- **Page**: IAM → Users → harmonic-ai-user → Security credentials → Create access key
- **Position**: Deuxième option (cercle à cocher)
- **Texte exact**: "Access key - Programmatic access"

## 🎯 ÉTAPES RAPIDES

1. **IAM** → **Users** → **Create user**
2. **User name**: `harmonic-ai-user`
3. **Next: Permissions**
4. **● Attach policies directly** ← COCHER
5. **Search**: `HarmonicAI-S3-Policy`
6. **☐ HarmonicAI-S3-Policy** ← COCHER
7. **Next: Tags** → **Next: Review** → **Create user**
8. **harmonic-ai-user** → **Security credentials**
9. **Create access key**
10. **● Access key - Programmatic access** ← COCHER
11. **Create access key**
12. **Copier** les clés
