## 🎮 **UTILISATION**

### **📸 Interface** :
1. **Caméra Originale** : Flux caméra en direct
2. **Résultat 8K** : Conversion HCS en temps réel
3. **Informations** : Résolution, PSNR, temps traitement

### **🎯 Contrôles** :

#### **📸 Prendre Photo 8K** :
- Cliquez sur le bouton vert
- Photo automatiquement sauvegardée
- Format : `hcs_8k_photo_YYYYMMDD_HHMMSS.jpg`

#### **🎬 Enregistrer Vidéo 8K** :
- Cliquez sur le bouton bleu
- Enregistrement commence
- Recliquez pour arrêter
- Format : `hcs_8k_video_YYYYMMDD_HHMMSS.mp4`

#### **🎯 Extraire Référence** :
- Cliquez sur le bouton orange
- Extrait profil chromatique du frame actuel
- Appliqué automatiquement aux traitements suivants
