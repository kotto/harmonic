## 📊 How It Works

### Entropy Analysis
```
Low entropy (< 2.0)   → zstd level 22 (ultra)
Medium entropy (2-4)  → zstd level 19 (high)
Normal entropy (4-6)  → zstd level 11 (balanced)
High entropy (> 6)    → zstd level 3 (fast)
```

### Compression Strategy
1. **Analyze entropy** of input data
2. **Select zstd level** based on entropy
3. **Compress** with selected level
4. **Fallback** to fast compression if needed
