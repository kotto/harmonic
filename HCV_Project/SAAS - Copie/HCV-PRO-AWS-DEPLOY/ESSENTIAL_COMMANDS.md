# ⚡ Commandes Essentielles - HCV-PRO-PROJECT\n\n## 🚀 Démarrage\n\n### Windows\n```bash\nstart.bat\n```\n\n### Linux/Mac\n```bash\nbash start.sh\n```\n\n### Manuel\n```bash\npython server/hcv_pro_server.py\n```\n\n---\n\n## 🌐 Accès\n\n### Interface Web\n```\nhttp://localhost:3000\n```\n\n### API Health\n```bash\ncurl http://localhost:3000/api/health\n```\n\n### Historique\n```bash\ncurl http://localhost:3000/api/history\n```\n\n---\n\n## 📡 Endpoints API\n\n### Démo Broadcast\n```bash\ncurl -X POST http://localhost:3000/api/demo\n```\n\n### Compression Android\n```bash\ncurl -X POST -F \"file=@image.jpg\" http://localhost:3000/api/android-boost\n```\n\n### Compression Vidéo\n```bash\ncurl -X POST -F \"file=@video.mp4\" http://localhost:3000/api/video-boost\n```\n\n### Compression Fichiers Précompressés\n```bash\ncurl -X POST -F \"file=@image.png\" http://localhost:3000/api/precompressed\n```\n\n---\n\n## 🔧 Installation\n\n### Installer les Dépendances\n```bash\npip install -r requirements.txt\n```\n\n### Réinstaller Complètement\n```bash\npip uninstall -r requirements.txt -y\npip install -r requirements.txt\n```\n\n---\n\n## 🛑 Arrêt\n\n### Arrêter le Serveur\n```bash\nCtrl+C\n```\n\n---\n\n## 🔍 Vérification\n\n### Vérifier Python\n```bash\npython --version\n```\n\n### Vérifier les Dépendances\n```bash\npip list | grep Flask\npip list | grep numpy\npip list | grep opencv\npip list | grep zstandard\n```\n\n### Vérifier le Port 3000\n```bash\n# Windows\nnetstat -ano | findstr :3000\n\n# Linux/Mac\nlsof -i :3000\n```\n\n---\n\n## 📚 Documentation\n\n### Guides Principaux\n- [README_FIRST.md](README_FIRST.md) -
