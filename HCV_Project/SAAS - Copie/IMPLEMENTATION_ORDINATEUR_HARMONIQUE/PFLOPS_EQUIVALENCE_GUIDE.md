## 📊 Formules Fondamentales

### 🌊 **PFLOps Relatif Complet**

```
PFLOps_Relatif = PFLOps_Réels × Facteur_Qualité × Facteur_Convergence

Où :
PFLOps_Réels = PFLOps mesurés sur le système harmonique
Facteur_Qualité = Précision_harmonique / Précision_standard
Facteur_Convergence = Epochs_standard / Epochs_harmonique
```

### 📐 **Composants Détaillés**

#### **1. Facteur de Qualité**
```
Facteur_Qualité = Précision_harmonique / Précision_standard

Exemples :
- 99.999976% / 99% = 1.00986
- 99.9999% / 95% = 1.053
- 100% / 90% = 1.111
```

#### **2. Facteur de Convergence**
```
Facteur_Convergence = Epochs_standard / Epochs_harmonique

Exemples :
- 100 / 24 = 4.17
- 50 / 12 = 4.17
- 200 / 50 = 4.0
```

#### **3. Facteur de Vitesse (optionnel)**
```
Facteur_Vitesse = Temps_standard / Temps_harmonique

Exemples :
- 2 heures / 2 minutes = 60
- 50ms / 12ms = 4.17
- 100ms / 25ms = 4.0
```
