## 🌊 Optimisations Harmoniques

### 📐 Constantes Fondamentales

Les optimisations utilisent les constantes harmoniques :

- **φ (phi)** : Nombre d'or pour l'optimisation des poids
- **π (pi)** : Constante du cercle pour les activations
- **e** : Nombre d'Euler pour la décroissance du taux d'apprentissage
- **√2** : Racine carrée de 2 pour les distances
- **√3** : Racine carrée de 3 pour l'équilibre

### 🔀 Algorithmes Optimisés

#### 1. Perceptron Harmonique

def harmonic_sigmoid(x):

def harmonic_learning_rate(epoch, lr):
    return lr * (1 + PHI / (epoch + 1)) * np.exp(-epoch / PI)
