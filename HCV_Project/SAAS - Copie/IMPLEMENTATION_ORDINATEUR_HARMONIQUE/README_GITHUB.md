## ⚛️ HBITS - QUBITS HARMONIQUES

Les **Hbits (Harmonic Bits)** sont des qubits géométriques basés sur 5 patterns fondamentaux :

### 🌀 Patterns Géométriques

1. **SPIRALE (φ)** - Spirale dorée, croissance fractale
2. **CERCLE (π)** - Symétrie radiale, périodicité
3. **HELICE (e)** - Torsion exponentielle, progression
4. **MIROIR (√2)** - Symétrie, dualité quantique
5. **TRINITÉ (√3)** - Équilibre ternaire, stabilité

### 🔢 Constantes Fondamentales

```python
φ = (1 + √5) / 2 ≈ 1.618033988749895  # Nombre d'or
π ≈ 3.141592653589793                  # Constante du cercle
e ≈ 2.718281828459045                  # Nombre d'Euler
√2 ≈ 1.414213562373095                # Racine carrée de 2
√3 ≈ 1.732050807568877                # Racine carrée de 3
```
