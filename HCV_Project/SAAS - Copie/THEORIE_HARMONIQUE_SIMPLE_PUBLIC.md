### **2.1 L'Idée Géniale**
> **Les constantes physiques sont des "points fixes" mathématiques**

**Qu'est-ce qu'un point fixe ?**
C'est une valeur qui reste **stable** quand on applique une opération mathématique.

**Exemple simple :**
Si R(α) = 1 - α²
Alors le point fixe satisfait : R(α*) = α*
Donc : 1 - α*² = α*
Ce qui donne : α*² + α* - 1 = 0
Solution : α* = 1/φ ≈ 0.618

### **2.2 Comment ça Marche**
Pour chaque constante C, il existe une opération R(C) telle que :
```
R(C*) = C*
```

**Exemples concrets :**
- **α** : R₁(α) = 1 - α² → α* = 1/φ
- **ℏ** : R₂(ℏ) = ℏ/φ + ℏ²/φ² → ℏ* = ℏ_expérimental
- **c** : R₃(c) = c/φ + c²/φ³ → c* = c_expérimental
- **G** : R₄(G) = G/φ² + G³/φ⁵ → G* = G_expérimental
