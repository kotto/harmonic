## 📖 **GUIDE D'UTILISATION DÉTAILLÉ**

### 🎯 **Étape par Étape**

1. **Ouvrir le fichier**
   ```
   Double-cliquer sur compression_standalone.html
   Ou faire clic droit → Ouvrir avec → Navigateur web
   ```

2. **Activer la licence**
   ```
   Cliquer sur "ACTIVER LICENCE VIBRANTE"
   Le statut passe de 🔒 à 🔓
   ```

3. **Sélectionner un fichier**
   ```
   Méthode 1 : Cliquer sur la zone d'upload
   Méthode 2 : Glisser-déposer un fichier
   Tous les formats sont supportés
   ```

4. **Configurer la compression**
   ```
   Mode : Ultra Fast → Quantum (plus lent = meilleur ratio)
   Sécurité : PHI Protected → Quantum Harmonic
   Options : Cocher selon besoins
   ```

5. **Lancer la compression**
   ```
   Cliquer sur "LANCER COMPRESSION VIBRANTE"
   Regarder l'animation vidéo
   Suivre la progression en temps réel
   ```

6. **Obtenir les résultats**
   ```
   Voir les statistiques détaillées
   Télécharger le fichier .hcvpro simulé
   Partager les résultats
   ```
