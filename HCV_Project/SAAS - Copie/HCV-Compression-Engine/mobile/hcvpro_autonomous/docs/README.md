# HCV PRO - Package Autonome Sécurisé

## Installation Complète

### Activation
```bash
python hcvpro.py license <votre_clé_licence>
```

### Compression
```bash
python hcvpro.py compress <fichier_input> <fichier_output>
```

### Informations
```bash
python hcvpro.py info
```
