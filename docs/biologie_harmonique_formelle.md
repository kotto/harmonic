## 7. La Phyllotaxie — Pourquoi les Plantes Ont la Forme qu'Elles Ont

### 7.1 L'angle d'or

```
Angle d'or = 360° / φ² = 137,5°

Chaque nouvelle feuille, chaque nouveau pétale,
chaque nouvelle graine de tournesol pousse
avec un angle de 137,5° par rapport à la précédente.
```

### 7.2 Pourquoi cet angle ?

```
Si l'angle était 180° (1/2 tour) :
  → Les feuilles se superposeraient tous les 2 tours
  → Elles s'ombrageraient mutuellement

Si l'angle était 120° (1/3 tour) :
  → Superposition tous les 3 tours → ombrage

Si l'angle était 90° (1/4 tour) :
  → Superposition tous les 4 tours → ombrage

Avec 137,5° = 360°/φ² :
  → φ² est irrationnel → JAMAIS de superposition exacte
  → Chaque feuille a un accès MAXIMAL à la lumière
  → La plante pousse de façon OPTIMALE
```

C'est la preuve la plus visible que **la nature « connaît » φ** et l'utilise pour optimiser la croissance.
