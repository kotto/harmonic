```

Si ses flèches tombent TRÈS PRÈS du centre → il est BON → χ² ≈ 26

L'archer harmonique a un score de 29,4 pour 26 flèches.
C'est presque PARFAIT. Les minuscules écarts qui restent sont
exactement ce que le vent (le hasard expérimental) explique.

Cet archer n'a PAS triché.
Il n'a PAS ajusté son arc avant chaque tir (0 paramètre libre).
Il a juste visé. Et il a touché.
```

## Version 2 — Le Test de Grossesse (pour un adulte)

```
Un test de grossesse fonctionne comme ceci :

  « H₀ : la femme n'est pas enceinte »    (hypothèse nulle)
  Si le test est POSITIF (p < 0,05) → on rejette H₀ → elle est enceinte.
  Si le test est NÉGATIF (p > 0,05) → on ne peut pas rejeter H₀.

Le test statistique pour une théorie physique fonctionne À L'ENVERS :

  « H₀ : la théorie est FAUSSE »           (hypothèse nulle)
  Si le test est POSITIF (p < 0,05) → on rejette H₀ → la théorie est... VRAIE ?
  NON ! Ça voudrait dire que la théorie est EXCLUE par les données !

En physique, on veut que le test soit NÉGATIF. On veut NE PAS pouvoir
rejeter la théorie. On veut que p soit GRAND.

Le χ² de la Théorie Harmonique donne p ≈ 0,30 (30%).
→ On ne peut PAS rejeter la théorie.
→ La théorie est PARFAITEMENT COMPATIBLE avec TOUTES les données.
→ Aucune mesure expérimentale ne la contredit.
```
