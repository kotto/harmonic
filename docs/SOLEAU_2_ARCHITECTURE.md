## 1. PRINCIPE GÉNÉRAL

Le Cerveau Harmonique est l'implémentation computationnelle de l'équation maîtresse Ψ = Σ Hₙ·(Ψ₁)ⁿ. Il s'agit d'un système de raisonnement automatique fondé sur l'interférence d'ondes dans l'espace vectoriel complexe ℂ⁵¹², sans aucun réseau de neurones, sans backpropagation, sans données d'entraînement.

## 2. ARCHITECTURE EN COUCHES

### Couche 1 — Encodage Holographique
```
Mot → FNV1a hash → distribution gaussienne → vecteur ℂ⁵¹²
Fait = v_sujet ⊛ v_relation ⊛ v_objet (convolution FFT / HRR)
```
- Dimension : 512
- Capacité théorique : ~40 000 mots sans collision
- Binding HRR : convolution circulaire par FFT
- Unbinding : corrélation circulaire

### Couche 2 — HolographicStore (INCONSCIENT)
```
H = Σ_f amplitude_f · ψ_f  (superposition additive)
```
- Stocke TOUS les faits sans filtre
- Retrieval pur par résonance : H ⊗ ψ_Q
- Apprentissage par répétition : amplitude += 1
- Oubli naturel : noyau ABC φ⁻ᵗ
- Index inversé + IDF + sous-mots pour rapidité

### Couche 3 — ConsciousFilter (CONSCIENT)
- Filtre par COHÉRENCE MUTUELLE des faits
- Applique les SFT (186 faits haute amplitude)
- Capacité limitée : traite N ≤ 5-10 faits
- FEEDBACK : renforce (accepté) ou affaiblit (rejeté)

### Couche 4 — Wave Decoder (EXPRESSION)
- Réalisation de surface avec connecteurs RST
- Détection du rôle discursif (addition, conclusion, contraste)
- Réponse adaptative : 1 fait → phrase simple, 2+ → paragraphe

## 4. RETRIEVAL — SCORING MULTI-FACTEUR

```
score = lexical × 0.7 + sémantique × 0.3 + bonus_sujet × 0.15 + bonus_relation × 0.10
weighted = score × amplitude_factor × boost_sujet_exact(×10) × sector_boost
```
- TF-IDF lexical + spectral embedding (PPMI)
- Boost sujet exact ×10 (priorité absolue)
- Boost secteur (code, médecine, droit, musique)
- Filtre strict : si 2+ tokens significatifs → exige ≥2 chevauchements
