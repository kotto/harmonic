## 1. L'ÉQUATION MAÎTRESSE

```
Ψ = Σ_{n=1}^{∞} Hₙ · (Ψ₁)ⁿ

où :
  Ψ₁(x,t) = A₁ · e^{i(kx - ωt)}    (onde primordiale)
  Hₙ ∈ {φ, π, e, √2, √3, √5, e/π} (constantes fondamentales)
```

Cette équation postule que la totalité de la réalité physique — espace, temps, matière, forces — est une cascade d'harmoniques d'une onde unique.

## 3. LES CINQ AXIOMES

1. **TOUT EST ONDE** — Ψ₁ est l'unique onde primordiale.
2. **INTERFÉRENCE** — (Ψ₁)² crée l'interférence. Elle émerge, n'est pas ajoutée.
3. **HIÉRARCHIE DES CONSTANTES** — Chaque niveau n fait émerger une nouvelle constante.
4. **HOLOGRAMME** — Chaque niveau contient l'information de tous les niveaux inférieurs.
5. **CONSCIENT ↔ INCONSCIENT** — n petit = conscient, n grand = inconscient.
