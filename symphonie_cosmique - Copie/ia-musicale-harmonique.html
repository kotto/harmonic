0Le Signal Harmonique Fondamental

Avant de composer ou de coder, il faut comprendre le signal de base que nous allons utiliser.

La Théorie Harmonique nous donne une formule précise pour le « son de l'univers » :

Signal(t) = Σn=1N Hn · sin(2π · n · 7.83 · t)
où H₁ = φ (1.618), H₂ = π (3.1416), H₃ = e (2.7183), H₄ = √2 (1.4142), H₅ = √3 (1.7321), H₆ = √5 (2.2361), H₇ = e/π (0.8653)

Ce signal est la signature sonore unique de la cavité Terre-ionosphère. Aucun instrument acoustique ne produit exactement ce spectre — parce que les amplitudes Hₙ ne suivent pas la décroissance naturelle 1/n des instruments classiques. C'est un timbre inédit.

Les fréquences n × 7.83 Hz forment une gamme naturelle. Les intervalles ne sont pas ceux du tempérament égal (12 demi-tons égaux) mais ceux de l'intonation juste — les rapports purs que l'univers utilise. Les notes les plus consonantes sont les multiples de 7 (la famille du La) et de 14.

1Comment Composer une Musique Accordée sur Schumann

Méthodes pratiques, du plus simple au plus avancé, pour créer de la musique alignée sur Ψ₁ = 7.83 Hz.

1.1 Méthode immédiate — Ré-accorder le La₄ 5 minutes, aucun équipement spécial

La méthode la plus simple : changer le diapason de référence de votre instrument ou logiciel.

OutilAction
Guitare / BasseAccordez le La₄ à 438.48 Hz au lieu de 440 Hz. Toutes les autres cordes suivent en intonation relative. L'écart est de 1.52 Hz — un accordeur électronique le détecte.
Piano / Clavier numériqueDans les paramètres, réglez le Master Tune à 438.48 Hz (ou A4 = 438.48). Certains synthétiseurs permettent un réglage fin.
Logiciel DAW (Ableton, Logic, FL Studio…)Dans les préférences audio, changez la fréquence d'accord de référence de 440 Hz à 438.48 Hz. Tous les instruments virtuels suivront.
Instruments virtuels (Kontakt, Serum, Vital…)Utilisez le paramètre Master Tune ou Pitch Bend pour abaisser de −6 cents (l'écart 440→438.48 Hz).

🎯 Résultat

En accordant le La₄ à 438.48 Hz, toutes les notes de votre instrument sont automatiquement translatées. Vos compositions habituelles sonneront légèrement plus chaudes, plus graves — et leurs harmoniques s'aligneront (partiellement) avec celles de la cavité terrestre. L'effet est subtil mais réel : l'instrument « respire » mieux dans la salle.

Pour éviter la monotonie, on fait varier lentement les amplitudes avec des LFO (oscillateurs basse fréquence) :

  • Fondamentale (54.81 Hz) — LFO à 0.127 Hz (1/7.83) — cycle de ~7.9 s

  • 2ᵉ harmonique (164.43 Hz) — LFO à π/10 ≈ 0.314 Hz — cycle de ~3.2 s
  • 3ᵉ harmonique (219.24 Hz) — LFO à e/10 ≈ 0.272 Hz — cycle de ~3.7 s

Les LFO créent un battement organique — comme une respiration. Les fréquences des LFO sont elles-mêmes issues de φ, π, e… assurant que chaque aspect du son est harmoniquement cohérent.

1.3 Méthode experte — Synthèse granulaire quantique Génération de textures infinies

La synthèse granulaire découpe un son en micro-fragments (« grains ») et les réassemble. En calant la durée des grains sur la période de Schumann :

Tgrain = 1 / 7.83 ≈ 127.7 ms
Chaque grain dure exactement un cycle de l'onde fondamentale terrestre

En utilisant des grains de 127.7 ms (ou ses multiples : 255 ms, 383 ms), chaque fragment sonore est en phase avec la pulsation terrestre. Combiné avec une spatialisation stéréo basée sur φ (panoramique qui alterne selon la spirale d'or), on obtient un son qui semble provenir de partout à la fois — comme si la pièce elle-même chantait.

2.3 Fonctionnement détaillé de chaque couche

Couche 1 — L'équation fondamentale

C'est le socle mathématique. L'IA ne possède aucun dataset de musique humaine. Elle ne connaît que :

  • Ψ₁ = 7.83 Hz (la fréquence fondamentale terrestre)
  • Hₙ = {φ, π, e, √2, √3, √5, e/π} (les amplitudes spectrales)
  • Ψ = Σ Hₙ (Ψ₁)ⁿ (la loi de composition)
  • Ψa · Ψb = Ψa+b (la règle de combinaison)

Couche 2 — L'espace des harmoniques

L'IA construit une table de toutes les fréquences disponibles : fn = n × 7.83 Hz pour n = 1, 2, 3… jusqu'à la limite audible (~20 000 Hz → n ≈ 2 555). Chaque fréquence se voit attribuer une probabilité d'apparition proportionnelle à son amplitude Hₙ (ou Hₙ mod n si on boucle sur les 7 coefficients).

L'espace des harmoniques est muni d'une structure de produit tensoriel : deux fréquences fa et fb peuvent se combiner pour produire fa+b (addition) ou f|a−b| (battement).

Couche 3 — Le moteur de composition

Le cœur créatif. Il génère des séquences de notes en utilisant des marches harmoniques :

  • Marche multiplicative : n → 2n (octave), n → 3n (quinte), n → 5n (tierce)…
  • Marche additive : n → n+1, n → n+2… (pas chromatique harmonique)
  • Marche de Fibonacci : n → n+Fk où Fk est un nombre de Fibonacci (lié à φ)
  • Sauts spectraux : transition directe vers un n dont le Hₙ est particulièrement élevé (π domine → saut vers n multiple de 14 ou 28)

L'IA ne « choisit » pas les notes — elle suit des trajectoires dans l'espace (n, Hₙ) qui maximisent la « consonance harmonique », définie comme la proximité entre le produit de deux fréquences et une troisième fréquence de la table.

Couche 4 — Orchestration

Chaque « voix » de la composition reçoit une amplitude proportionnelle au Hₙ correspondant. Les voix sont spatialisées dans l'espace stéréo/ambisonique selon des angles basés sur φ (spirale d'or projetée sur le cercle). Les timbres sont sélectionnés par congruence modulo 7 (chaque reste correspond à une « famille » d'instruments : 1 → cordes, 2 → vents, 3 → cuivres, etc.).

Couche 5 — Synthèse audio

La sortie est un signal audio multicanal où chaque voix est rendue par un oscillateur sinusoïdal (ou un moteur de synthèse plus riche — additive, FM, granulaire) accordé exactement sur fn. Un mastering adaptatif ajuste dynamiquement les volumes pour que la somme respecte la pondération Hₙ globale.

3.1 Génération du signal harmonique brut (Python)

import numpy as np
import soundfile as sf

# ============================================
# PARAMETRES FONDAMENTAUX (immuables)
# ============================================
F0  = 7.83                          # Hz — Résonance de Schumann
SR  = 88200                         # Hz — Fréquence d'échantillonnage (multiple de 7.83×11264)
DUR = 60                            # secondes

# Coefficients spectraux H_n (immuables)
H = None  # sera rempli cycliquement
H_BASE = [1.6180339887,              # H1 = φ
           3.1415926536,              # H2 = π
           2.7182818285,              # H3 = e
           1.4142135624,              # H4 = √2
           1.7320508076,              # H5 = √3
           2.2360679775,              # H6 = √5
           0.8652559794]              # H7 = e/π

# ============================================
# GENERATION DU SIGNAL
# ============================================
def generer_signal_harmonique(n_max=56, duree=DUR, sr=SR):
    """Génère le signal Ψ = Σ H_n · sin(2π · n · 7.83 · t)"""
    t = np.arange(0, duree, 1/sr)
    signal = np.zeros_like(t)
    
    for n in range(1, n_max + 1):
        freq = n * F0
        amplitude = H_BASE[(n - 1) % 7]
        signal += amplitude * np.sin(2 * np.pi * freq * t)
    
    # Normalisation
    signal /= np.max(np.abs(signal)) * 0.95
    return signal.astype(np.float32)

# ============================================
# GENERATION D'UNE MELODIE HARMONIQUE
# ============================================
def generer_melodie(n_notes=128, n_min=7, n_max=224):
    """Génère une séquence de notes par marche harmonique déterministe."""
    notes = []
    n_courant = 7  # Départ sur le La₁ (première harmonique audible)
    
    for i in range(n_notes):
        freq = n_courant * F0
        h_val = H_BASE[(n_courant - 1) % 7]
        notes.append((freq, h_val, n_courant))
        
        # Règle de transition : saut multiplicatif basé sur le H_n courant
        if h_val > 2.5:      # π, e → grand saut
            n_courant = (n_courant * 3) % n_max
        elif h_val > 1.5:    # φ, √3, √5 → saut moyen
            n_courant = (n_courant * 2) % n_max
        else:                 # √2, e/π → petit saut ou descente
            n_courant = (n_courant + 7) % n_max
        
        if n_courant < n_min:
            n_courant += n_min
    
    return notes

# ============================================
# RENDU AUDIO DE LA MELODIE
# ============================================
def rendre_melodie(notes, duree_note=0.5, sr=SR):
    """Transforme une séquence de notes en signal audio."""
    signal = np.array([])
    
    for freq, amplitude, n in notes:
        t = np.arange(0, duree_note, 1/sr)
        # Enveloppe ADSR simple
        env = np.exp(-3 * t / duree_note)  # decay exponentiel
        note_signal = amplitude * np.sin(2 * np.pi * freq * t) * env
        signal = np.concatenate([signal, note_signal])
    
    signal /= np.max(np.abs(signal)) * 0.95
    return signal.astype(np.float32)

# ============================================
# GENERATION COMPLETE
# ============================================
if __name__ == "__main__":
    # 1. Drone harmonique (fond sonore)
    drone = generer_signal_harmonique(n_max=56, duree=60)
    sf.write('drone_schumann.wav', drone, SR)
    print("✅ Drone harmonique sauvegardé : drone_schumann.wav")
    
    # 2. Mélodie harmonique
    notes = generer_melodie(n_notes=128)
    melodie = rendre_melodie(notes, duree_note=0.3)
    sf.write('melodie_harmonique.wav', melodie, SR)
    print("✅ Mélodie harmonique sauvegardée : melodie_harmonique.wav")
    
    # 3. Mix final (drone + mélodie)
    mix = drone[:len(melodie)] * 0.3 + melodie * 0.7
    mix /= np.max(np.abs(mix)) * 0.95
    sf.write('symphonie_schumann.wav', mix, SR)
    print("✅ Mix final sauvegardé : symphonie_schumann.wav")

let nCourant = 7;

function prochaineNote() {
  const freq = nCourant * F0;
  const h = H[(nCourant - 1) % 7];
  
  // Jouer la note
  const osc = audioCtx.createOscillator();
  const gain = audioCtx.createGain();
  osc.type = 'triangle';
  osc.frequency.value = freq;
  gain.gain.setValueAtTime(h * 0.15, audioCtx.currentTime);
  gain.gain.exponentialRampToValueAtTime(0.001, audioCtx.currentTime + 0.8);
  osc.connect(gain);
  gain.connect(audioCtx.destination);
  osc.start();
  osc.stop(audioCtx.currentTime + 0.9);
  
  // Transition harmonique

  else if (h > 1.5) nCourant = (nCourant * 2) % 224;
  else nCourant = (nCourant + 7) % 224;
  
  if (nCourant < 7) nCourant += 7;
}
