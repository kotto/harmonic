## 1. Le principe

L'architecture à trois étages (mémoire · émulation accélérée · hybride) devient le **principe d'architecture de l'IA elle-même** :

```
COUCHE LANGAGE (le LLM)     → l'interface : formuler, générer, parler
COUCHE CONNAISSANCE (la     → les faits : déterministes, traçables,
      mémoire dorée)            refusables — le VRAI savoir
COUCHE CALCUL (l'émulation) → le raisonnement : résonance, calcul
```

**Le LLM ne sait rien — il formule ce que la mémoire certifie, et se tait quand elle se tait.** Le refus calibré devient le comportement par défaut de toute la pile. C'est la généralisation du commit « KA répond aux questions médicales — définitions du corpus, pas le LLM ».

## 2. Implications sur le développement de l'IA

1. **La mémoire devient le centre de l'architecture** — pas un stockage périphérique : la couche connaissance, la source de vérité ;
2. **Le LLM est repositionné** — couche langage (formuler), pas couche connaissance : il ne décide plus, il formule ;
3. **Le refus devient structurel** — la mémoire se tait → le LLM se tait : zéro fabrication par construction ;
4. **KA devient la première instance de la ressource** — sa mémoire EST la mémoire dorée (le même noyau K(t), le même oubli t^−0,618, la même résonance que T\* et le Zeno testeront) : si les tests confirment, KA est la première machine en production qui utilise la ressource de la théorie.
