# 📊 Tableau Périodique — Particules et Éléments

## Description
Classification harmonique de la matière. 118 éléments chimiques, 18 particules classées,
30 particules prédites, bloc g (Z=121-138). Théorème T6 : 7 types × itérations.

## Fonctionnalités
- **118 éléments** : 7/7 gaz nobles, pic de fer Ni-62, 7 périodes
- **18 particules classées** : leptons, quarks, bosons, Higgs
- **30 particules prédites** : 5 à ~keV, 4 à < eV, 21 à M_Pl
- **Théorème T6** : structure modulo 7, 7 types × itérations
- **Bloc g** : prédiction des éléments 119-138
