# 🔬 HarmoFold — Repliement de Protéines

## Description
Repliement de protéines par cascade de résonance harmonique.
6 termes physiques, zéro paramètre appris, zéro base PDB.

## Fonctionnalités
- **Score Ramachandran** : 0.71–0.78 (comparable PDB 2.0 Å)
- **Zéro paramètre** : connaissance physique pure, pas d'apprentissage
- **Cascade de résonance** : oscillateurs couplés, pas de ML
- **6 termes physiques** : liaison, angle, torsion, van der Waals, électrostatique, solvatation
