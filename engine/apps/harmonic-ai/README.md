# 🧠 Harmonic AI — Langage Ondulatoire

## Description
IA harmonique fondée sur le langage ondulatoire (13 primitives).
Raisonnement par résonance, zéro hallucination, apprentissage en 3-5 répétitions.

## Fonctionnalités
- **13 primitives** : encode, decode, bind, resonate, superpose, interfere, diffract, filter, phase_shift, rotate, normalize, amplify, emerge
- **Wave Compiler** : 4 passes d'optimisation, roundtrip bit-à-bit
- **Wave IR** : AST, sérialisation JSON
- **Zero Hallucination** : refus calibré, architecture déterministe
- **Harmonic Transformer** : attention O(n log n), 7 états
- **Conscious Engine** : créateur + critique autonome
