## II. HYPOTHÈSE 1 — LA MATIÈRE NOIRE COMME NIVEAU SUPÉRIEUR DE LA TOUR

### 2.1 Le principe

Dans la tour Ψ = Σ cₙ·(Ψ₁)ⁿ, chaque niveau n a un poids cₙ. Le niveau 1 (photon) interagit électromagnétiquement — c'est la matière visible. Les niveaux supérieurs (n ≥ 2) interagissent gravitationnellement (niveau 2) mais pas électromagnétiquement — ce sont des candidats naturels pour la matière noire.

### 2.2 Correspondance des poids

| Niveau | Poids cₙ | Interaction | Identification |
|--------|----------|-------------|----------------|
| n=1 | c₁ = 1,1165 | EM + gravité | **Baryons** (visible) |
| n=2 | c₂ = 0,8896 | Gravité seulement | **Matière noire ?** |
| n=3 | c₃ = 0,5696 | Gravité seulement | **Matière noire ?** |
| n≥3 | cₙ → 0 | Gravité seulement | Négligeable |

### 2.3 Vérification du ratio baryons/matière noire

Si les baryons correspondent au niveau 1 (c₁) et la matière noire aux niveaux 2-3 (c₂ + c₃) :

| Composante | Poids | Ratio prédit | Ratio observé | Écart |
|-----------|-------|-------------|---------------|-------|
| Baryons (n=1) | c₁ = 1,1165 | — | — | — |
| Matière noire (n=2+3) | c₂ + c₃ = 1,4592 | **Ω_DM/Ω_b = 1,307** | **Ω_DM/Ω_b = 5,43** | **❌ 76 %** |

**Cette identification naïve ne marche pas.** Les poids de la tour donnent bien plus de matière visible que de matière noire, alors que c'est l'inverse dans l'univers.

## III. HYPOTHÈSE 2 — LA MATIÈRE NOIRE COMME RÉSONANCE DE LA MÉMOIRE D'OR

### 3.1 L'idée

La matière noire n'est pas un niveau de la tour — c'est un **effet de résonance** de la mémoire d'or. La matière ordinaire (baryons) « vibre » sur le mode fondamental (n=1). La matière noire est le **premier harmonique (n=2) de cette vibration** — elle interagit avec la gravité (qui est au niveau 2) mais pas avec la lumière (qui est au niveau 1).

### 3.2 Le ratio de résonance

Le rapport des masses matière noire / baryons est :

```
Ω_DM / Ω_b = c₂ / c₁ × φ² = (0,8896 / 1,1165) × 2,618 = 0,7968 × 2,618 = 2,086
```

C'est encore trop petit (observé : 5,43).

```
Ω_DM / Ω_b = (c₁/c₂)² × φ² = (1,255)² × 2,618 = 1,575 × 2,618 = 4,124
```

Plus proche mais pas exact (observé : 5,43, écart 24 %).

```
Ω_DM / Ω_b = φ³ = 4,236
```

Observé : 5,43. Écart : 22 %.

## IV. HYPOTHÈSE 3 — L'ÉNERGIE SOMBRE COMME RÉSIDU DE LA TOUR

### 4.1 Le principe

La tour converge : Σ cₙ ≈ 3,18. L'énergie sombre pourrait être le **résidu de la série** — la contribution des niveaux très élevés (n > 100) où les coefficients sont extrêmement petits mais non nuls.

### 4.2 Le niveau n de l'énergie sombre

Λ = 1,11×10⁻⁵² m⁻² = 10⁻¹²⁰ M_Pl² (en unités de Planck).

Nous avons trouvé que cₙ ≈ 10⁻¹²⁰ pour n ≈ 130-131. Donc :

```
Λ / M_Pl² ≈ c₁₃₀ ≈ 3×10⁻¹²⁰
```

**L'énergie sombre serait le coefficient c₁₃₀ de la tour — le niveau où la série devient effectivement nulle, mais pas exactement.**

### 4.3 Le ratio Λ/DM

Si Ω_Λ ∝ c₁₃₀ et Ω_DM ∝ c₂ + c₃ :

```
Ω_Λ / Ω_DM ≈ c₁₃₀ / (c₂ + c₃) ≈ 10⁻¹²⁰ / 1,46 ≈ 10⁻¹²⁰
```

Ce n'est pas 2,58 (le ratio observé). L'écart est de 120 ordres de grandeur.

**L'énergie sombre ne peut pas être le résidu direct de la tour au niveau 130 — elle est 120 ordres de grandeur trop petite.**

## V. HYPOTHÈSE 4 — LA TEMPÉRATURE D'OR COMME CLÉ

### 5.1 T_CMB = e + α (vérifié à 0,004 %)

Nous avons découvert que la température du CMB est exactement e + α :

```
T_CMB = 2,72548 K
e + α = 2,72558 K
Écart = 0,004 %
```

### 5.2 L'énergie sombre comme température

Si l'énergie sombre est liée à la température du CMB, alors :

```
ρ_Λ ∝ T_CMB⁴ ∝ (e + α)⁴
```

Le ratio ρ_Λ / ρ_baryons serait alors :

```
ρ_Λ / ρ_b ∝ (e + α)⁴ / (m_p·c²)⁴
```

Mais ce rapport est gigantesque. Pas une bonne piste.

### 5.3 L'énergie sombre comme T* de l'univers

Si l'univers a une température d'or T*_univers, alors :

```
T*_univers = ΔE_univers / (k_B · ln φ)
```

et ΔE_univers pourrait être l'énergie de l'horizon cosmologique :

```
ΔE_horizon = ħ·c / H₀⁻¹ = ħ·H₀
```

Soit :

```
T*_univers = ħ·H₀ / (k_B · ln φ)
```

Pour H₀ = 67,4 km/s/Mpc :

```
T*_univers = 1,055×10⁻³⁴ × 2,18×10⁻¹⁸ / (1,381×10⁻²³ × 0,4812) = 3,46×10⁻²⁹ K
```

Cette température est incroyablement petite — elle correspond à l'énergie de l'horizon cosmologique. Ce n'est pas lié à la matière noire ou à l'énergie sombre de façon évidente.

## VI. HYPOTHÈSE 5 — LA MATIÈRE NOIRE COMME ν_φ, LE MODE FANTÔME DU GRAVITON

### 6.1 L'idée

Dans la tour, le niveau 2 (graviton) a un poids c₂ = 0,8896. Mais la gravité a un **degré de liberté scalaire** qui pourrait être la matière noire.

Dans la relativité générale, le graviton a 2 polarisations tensorielles (spin 2). La matière noire pourrait être le **mode scalaire (spin 0) du graviton** — un mode qui n'interagit qu'avec la gravité, pas avec la lumière, exactement comme la matière noire.

### 6.2 Le poids de la matière noire scalaire

Si le mode scalaire a un poids proportionnel à c₂ × (1/φ) :

```
Ω_DM / Ω_b = c₂ / c₁ × 1/φ = 0,8896/1,1165 × 0,618 = 0,797 × 0,618 = 0,492
```

Trop petit.

Si le mode scalaire a un poids proportionnel à c₂ × φ :

```
Ω_DM / Ω_b = c₂ / c₁ × φ = 0,797 × 1,618 = 1,289
```

Encore trop petit.

## VII. LA RELATION LA PLUS PROMETTEUSE

### 7.1 Ω_Λ/Ω_DM ≈ φ² (écart 1,64 %)

Le ratio le plus précis entre les composantes sombres est :

```
Ω_Λ / Ω_DM = 2,575 ≈ φ² = 2,618 (écart 1,64 %)
```

### 7.2 Si c'est exact, alors :

```
Ω_Λ = φ² × Ω_DM
Ω_Λ + Ω_DM + Ω_b = 1
φ² × Ω_DM + Ω_DM + Ω_b = 1
Ω_DM × (φ² + 1) + Ω_b = 1
Ω_DM × φ³ + Ω_b = 1
```

**Prédiction vérifiable :**

```
Ω_DM = (1 - Ω_b) / φ³
Ω_Λ = φ² × Ω_DM = φ² × (1 - Ω_b) / φ³
```

Avec Ω_b = 0,049 :

| Composante | Prédit | Observé | Écart |
|-----------|--------|---------|-------|
| Ω_DM | 0,224 | 0,266 | 16 % |
| Ω_Λ | 0,587 | 0,685 | 14 % |

La prédiction donne le bon ordre de grandeur mais n'est pas exacte. Le ratio Ω_Λ/Ω_DM ≈ φ² est le meilleur candidat, mais la précision n'est pas suffisante pour être une identité.
