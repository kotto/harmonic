Questions fréquentes

Tout ce que vous devez savoir sur HCV2 Pro.

Qu'est-ce que la compression harmonique ?

La compression harmonique utilise la Théorie Harmonique Universelle (THU) pour décomposer l'image dans le domaine fréquentiel via une FFT 2D, puis applique un seuil doré (basé sur le nombre d'or φ) pour ne garder que les coefficients perceptuellement significatifs. Le dictionnaire de patches mémorise les motifs récurrents et permet des ratios lossless jusqu'à 213×.

Le format .hcv2 est-il ouvert ?

Oui, la spécification complète du format .hcv2 v1.0 est publique. Le décodeur est libre (WASM 81 Ko, C, Python). Il n'y a pas de verrouillage propriétaire — vos données restent accessibles sans notre logiciel.

Quels sont les ratios de compression réels ?

Sur une collection homogène (même caméra, même décor) : 213× lossless. Sur contenu broadcast standard : 59-373× selon le mode. Sur contenu inconnu : 2,9-72× (le sélecteur choisit automatiquement le meilleur mode).

Le dictionnaire est-il obligatoire ?

Non. Le codec fonctionne sans dictionnaire (mode FULL : 2,9× lossless). Le dictionnaire est un bonus qui multiplie le ratio par 10-100× sur les contenus cohérents. Le dictionnaire broadcast est inclus dans toutes les offres.

Quels sont les prérequis techniques ?

Python 3.10+, numpy, pillow, opencv-python, zstandard. Le décodeur WASM 81 Ko ne nécessite aucune installation. Le serveur API nécessite Flask (installé automatiquement).

Comment se passe l'intégration ?

API REST : 3 endpoints (compress, info, status). CLI : 7 commandes (encode, decode, info, checksum, batch, dict, serve). L'intégration prend moins d'une heure. Nous accompagnons chaque nouveau client.

Y a-t-il une version d'essai ?

Oui, nous proposons une démo gratuite de 30 jours avec 100 Go de quota. Remplissez le formulaire de contact ci-dessous pour recevoir vos accès.

Le codec est-il compatible avec mon logiciel ?

HCV2 Pro s'intègre via API REST ou CLI dans n'importe quel pipeline. Nous avons des adaptateurs pour : Avid Media Composer, DaVinci Resolve, Premiere Pro, After Effects, Nuke, Fusion. Contactez-nous pour un adaptateur spécifique.
