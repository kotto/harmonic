🚀 API HCV2 Pro

Compressez une image en une ligne :

curl -X POST https://api.hcv2.pro/compress \
-F "image=@fichier.dpx" \
-F "quality=archive" \
-o resultat.hcv2

🐍 Avec Python :

from hcv2_pro import encode, decode
encode("video.dpx", "archive.hcv2", quality="archive")
decode("archive.hcv2", "restore.dpx")
