## 1. La correction

L'analyse initiale dimensionnait le marché par « qui croit à la physique harmonique » — le sommet visible d'une petite API. **Trois erreurs** :

1. **Le marché n'est pas les croyants** — c'est quiconque a besoin de calcul vectoriel déterministe : embeddings, retrieval, RAG, audit. Ils n'ont rien à croire : le produit fonctionne (37 tests, playground public, reproductible par commande). La théorie est la douve ; le produit est la pointe.
2. **Le SaaS est un coin, pas le produit final** — le langage ondulatoire est la plateforme (un paradigme de calcul vectoriel avec mémoire), le matériel est l'horizon. Dimensionner le coin, c'est oublier l'océan.
3. **Le plus grand segment est le marché du soulagement** — des millions d'entreprises hantées par le quantique (« sommes-nous prêts ? »). L'annonce vend la fin de la peur : *« le quantum-like est déjà là, sur votre portable »*.

**La prémisse, corrigée honnêtement** : un portable ne fera pas des calculs « aussi puissants qu'un QPU » (pas d'accélération, registre natif n ≤ 9). Mais il fera ce que les entreprises **achètent aujourd'hui** au nom du quantique — le quantum-inspired (D-Wave, Fujitsu le vendent depuis 2018), le calcul vectoriel, la confiance — déterministe, maintenant, reproductible.

## 6. La psychologie de l'annonce — le marché du soulagement

**La FOMO se convertit en adoption** : les entreprises n'achètent pas la physique — elles achètent la **réassurance** (« nous ne raterons pas le quantique ») et l'**utilité** (« ça résout un problème aujourd'hui »). L'annonce offre les deux pour 29 €/mois au lieu de $100M :

```
AVANT :  « le quantique arrive » → peur → pilotes chers → rien de productif
APRÈS :  « le quantum-like est déjà là » → test → adoption → le produit vit
```

**Le point décisif** : le produit **fonctionne** — le marché n'achète pas une promesse, il achète un service qui répond à une requête, vérifiable avant paiement. C'est la différence avec toutes les annonces quantiques précédentes : celles-ci annonçaient des machines ; celle-ci annonce une **API qui marche sur un portable** — et le client peut le vérifier en deux minutes.
