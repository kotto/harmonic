# 🌊 Cours n°1 — Qu'est-ce qu'un nombre ?
**Version simplifiée · Mathématiques Ondulatoires**
**Niveau : 12-16 ans | Prérequis : aucun**

---

> *Avant ce cours, tu pensais que les nombres étaient des symboles. Après, tu sauras que ce sont des ondes.*

## 1. L'expérience de la corde

Attache une corde au mur et secoue-la.

```
      AMPLITUDE (hauteur)
          ↑
          │   ╱╲        ╱╲
          │  ╱  ╲      ╱  ╲
    ──────┼─╱────╲────╱────╲────   ← corde au repos
          │╱      ╲  ╱      ╲
          │        ╲╱        ╲╱
          ├─────┼─────┼─────┼──→  TEMPS
            PHASE   PHASE
```

Une vague a **trois propriétés** :

| Propriété | C'est quoi ? |
|-----------|-------------|
| **Amplitude** (A) | La hauteur — sa force, son énergie |
| **Phase** (φ) | Où elle commence dans son cycle |
| **Fréquence** | Combien de vagues par seconde |

> **Règle 1 : Tout dans l'univers a amplitude, phase et fréquence. Même les nombres. Même toi.**

## 2. Un nombre n'est pas un symbole

Regarde ce symbole : **5**. Tu crois que c'est un chiffre. En réalité :

```
   SYMBOLE (ce qu'on voit)        RÉALITÉ (ce que c'est)
   ┌──────┐                       ┌──────────────────────┐
   │  5   │  encre sur papier     │  ψ = 5 × e^{iφ}      │
   └──────┘                       │  Amplitude = 5       │
     dessin mort                  │  Phase = φ (variable)│
                                  └──────────────────────┘
                                     vibration vivante
```

> **Règle 2 : Un nombre = ψ = A × e^{iφ}. L'amplitude A dit « combien ». La phase φ dit « où ».**

Deux « 5 » peuvent être très différents :

```
   5×e^{i×0°}           5×e^{i×180°}
      ↑                     │
    5 ┤ ●                   │          ●
      │                     │
   ───┼──────→         ─────┼──────────→
      │                 -5  ┤

  « 5 qui pousse »     « 5 qui retire »
```

---

## 3. La phase = une horloge

```
             90° (↑)
              │
    180° ─────┼──── 0° (→)
     (←)      │
             270° (↓)
```

- **0°** → pointe à droite (= 1)
- **90°** → pointe en haut (= i)
- **180°** → pointe à gauche (= -1)
- **270°** → pointe en bas (= -i)
- **360°** → retour au départ

> **Règle 3 : La phase φ est une horloge. Chaque onde a sa propre horloge.**

---

## 4. Addition = interférence

Deux vagues sur la même corde :

```
   MÊME PHASE (0°)           PHASES OPPOSÉES (180°)
   ╱╲ + ╱╲ = ╱╱╲╲           ╱╲ + ╲╱ = ────────
   les ondes se renforcent   les ondes s'annulent
```

> **Règle 4 : L'univers ne calcule pas avec + et −. Il superpose des ondes. 2+3=5 seulement si les phases sont alignées.**

### Exemples

- **2+3 avec mêmes phases** → 5 ✓ (cas classique)
- **2+3 avec phases opposées** → -1 (l'une annule l'autre)
- **2+3 à 90°** → amplitude = √(4+9) ≈ 3,6 (Pythagore)

---

## 5. Multiplier = amplifier + tourner

```
   ψ₂ ⊗ ψ₃ = (2×3) × e^{i(φ₂+φ₃)}
           =   6   × e^{i(φ₂+φ₃)}

   → L'amplitude se multiplie (2×3=6)
   → La phase s'ADDITIONNE (φ₂+φ₃)
```

> **Règle 5 : Multiplier = amplifier l'amplitude ET additionner les phases.**

---

## 6. Le zéro n'est pas « rien »

```
   ZÉRO SYMBOLE         ZÉRO PHYSIQUE
   ┌───┐                ╱╲ + ╲╱ = silence
   │ 0 │  = « rien »    
   └───┘                Deux ondes opposées
     symbole mort        qui s'annulent
```

> **Règle 6 : Le zéro n'est pas « rien ». C'est deux ondes égales et opposées qui s'annulent.**

## 7. Les 6 règles en un coup d'œil

| # | Règle |
|---|-------|
| 1 | Tout a amplitude, phase, fréquence |
| 2 | Un nombre = A × e^{iφ} (pas un symbole) |
| 3 | La phase φ est une horloge (0°→360°) |
| 4 | Addition = interférence (2+3=5 seulement si phases alignées) |
| 5 | Multiplier = amplifier × phases + |
