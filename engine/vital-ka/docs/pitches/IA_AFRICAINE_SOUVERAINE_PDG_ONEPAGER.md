## La thèse en une phrase
> **Une pile technologique africaine complète, fonctionnelle aujourd'hui : IA déterministe sans dépendance étrangère, santé numérique offline, et réseau optimisé — un moteur, trois applications, zéro donnée qui sort du continent.**

## Le problème que MTN veut résoudre
| Obstacle de l'IA étrangère (OpenAI/Google/Anthropic) | Conséquence pour l'Afrique |
|---|---|
| Dépendance totale : API étrangères, prix en USD, coupures possibles | Aucune souveraineté — le service peut disparaître du jour au lendemain |
| **Hallucinations** : le LLM invente des réponses | Inacceptable pour banque, santé, justice, administration |
| **Les données sortent du continent** | Violation des régulateurs (POPIA, NDPR, lois africaines émergentes) |
| Coût : GPU, datacenters, consommation électrique | Inaccessible pour la majorité des entreprises africaines |

## Ce que nous avons construit — une pile, trois applications

### 🧠 1. IA — KA Enterprise : l'IA souveraine, déterministe
- **Zéro LLM, zéro appel externe** : la réponse est *retrouvée* par résonance dans les données de l'entreprise, pas *générée* — si l'information n'y est pas, l'IA dit « je ne sais pas » ;
- **Déterminisme absolu** : même question + mêmes documents = même réponse, traçable (SHA256) — l'auditabilité exigée par les banques et l'État ;
- **Tourne sur serveur CPU standard** (Niveau 1, disponible aujourd'hui), trajectoire FPGA → ASIC → optique ;
- **100 % souveraine** : vos données ne quittent jamais votre infrastructure.

### 🏥 2. Santé — VITAL KA : la preuve terrain (Cameroun)
- Diagnostic IA **offline** (44 pathologies), dossier patient chiffré, paiement santé (UM) sur MTN MoMo ;
- **En cours de déploiement avec MTN Cameroun** : MoU pilote, 200 pharmacies, Extrême-Nord — la preuve de production de la technologie.

### 🌐 3. Réseau — Compression harmonique HCV : la souveraineté de la bande passante
- 2–10× sur les flux réels, latence < 2 ms, sans modification des terminaux ;
- **US$150–300 M/an d'économies potentielles pour le groupe MTN** (modèle sur données publiques FY2025) ;
- La bande passante est aussi une question de souveraineté : chaque bit économisé est de la capacité achetée en moins.
