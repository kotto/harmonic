# MODÈLE KA — CORPORATION & FONDATION

## 1. La place de chacune — la frontière sacrée

```
┌──────────────────────────────────────────────────────────────────────────┐
│                        KA CORPORATION (commercial)                       │
│  DOMAINE : la technologie et le marché                                     │
│  ▸ Plateforme VITAL KA (apps, diagnostic, wallet UM)                      │
│  ▸ Infrastructure UM + intégration MTN MoMo (fees 1 %, abonnements)       │
│  ▸ Réseau professionnel B2B : médecins, pharmacies, labos                 │
│  ▸ Contrats commerciaux : MTN Cameroun, MINSANTE (prestations), opérateurs│
│  ▸ Moteur de compression HCV — deals B2B TELECOMS (phase 3)               │
│  ▸ Écosystème KA Mobile, KA Enterprise — la preuve technique              │
│  ▸ Propriété intellectuelle : marques, code, bases (détenues ici ou via   │
│    véhicule Suisse)                                                       │
│  REVENUS : fees UM · abonnements · licences · B2B · compression           │
│  FINANCEMENT : fondateurs + investisseurs (pas de dons)                   │
├──────────────────────────────────────────────────────────────────────────┤
│                        KA FONDATION (non lucratif)                        │
│  DOMAINE : l'impact social                                                 │
│  ▸ Collecte de dons diaspora (reçus fiscaux 66 % — véhicule Irlande/UE)   │
│  ▸ Financement des SOINS des patients démunis (le patient ne paie jamais) │
│  ▸ Projets ruraux co-brandés (Fondation MTN, Y'ello Care, Extrême-Nord)   │
│  ▸ Partenariats bailleurs : AFD, UE, fondations internationales           │
│  ▸ Relation institutionnelle : MINSANTE, CNERSH, ODD 3 (protocole)        │
│  ▸ Rapports d'impact publics, transparence, plaidoyer                     │
│  REVENUS : dons (individuels, associations, bailleurs)                    │
│  FINANCEMENT : donateurs uniquement — jamais de fonds commerciaux          │
└──────────────────────────────────────────────────────────────────────────┘
```

**La règle qui rend le modèle possible (3 lignes) :**
1. **Seule la Fondation reçoit des dons** — elle seule émet des reçus fiscaux ;
2. **La Fondation finance des soins, jamais de la R&D ni du marketing** — l'argent des donateurs n'achète que des consultations, des médicaments, des accouchements ;
3. **La Corporation fournit la plateforme à la Fondation à prix coûtant** (convention publiée) — pas de marge sur l'argent caritatif, pas de conflit.

### 1.1 Le portefeuille produits — KA Mobile et KA Enterprise sont des produits de la Corporation

Les deux produits appartiennent **exclusivement à la Corporation** (commercial). Leur place dans l'écosystème :

```
┌──────────────────────────────────────────────────────────────────────┐
│              KA CORPORATION — 4 lignes, un seul moteur               │
│                                                                      │
│  LIGNE 1 · SANTÉ (VITAL KA)          LIGNE 2 · CONSOMMATEUR          │
│  ▸ Diagnostic IA offline, UM, MoMo    ▸ KA MOBILE — l'app grand      │
│  ▸ Réseau pharmacies/médecins         public (photos, IA personnelle,│
│  ▸ Pilote MTN/MINSANTE                émotions vocales, launcher)    │
│                                       ▸ RÔLE : la PORTE D'ENTRÉE —   │
│                                       la diaspora télécharge KA      │
│                                       Mobile, découvre Solidarité et │
│  LIGNE 3 · ENTREPRISE (B2B)           VITAL KA. La preuve technique  │
│  ▸ KA ENTERPRISE : IA souveraine      (téléchargements, avis).       │
│    sans LLM (Niveaux 1-4, CPU→ASIC)   ▸ Revenus : premium, modestes  │
│  ▸ COMPRESSION HCV TELECOM (phase 3)                                 │
│  ▸ RÔLE : LE MOTEUR DE REVENUS —      ⚙️ Moteur commun : IA          │
│    finance la Corporation et donc     harmonique, langage ondulatoire│
│    l'écosystème (hôpitaux, assureurs, ▸ Coûts partagés, P&L séparées │
│    ministères, opérateurs)            ▸ Devs communs, ventes dédiées │
│                                                                      │
│  LIGNE 4 · COMPUTE (DATACENTERS)                                     │
│  ▸ Trajectoire HPU : FPGA → ASIC → optique (H-Bit, résonance)        │
│  ▸ AUJOURD'HUI : rien à vendre en matériel — la Ligne 4 prépare      │
│  ▸ DEMAIN : accélérateur FPGA en co-développement industriel         │
│  ▸ RÔLE : le récit « datacenter souverain africain » — l'IA sans GPU │
│    + la compression HCV (Lignes 2-3) = la preuve qui précède la      │
│    Ligne 4. Ne se vend jamais avant d'être mesurée.                  │
└──────────────────────────────────────────────────────────────────────┘
```

**Les 4 règles de synergie entre les lignes :**
1. **KA Mobile = gratuit pour la Fondation** (licence caritative, cohérente avec la règle du prix coûtant) — la Fondation bénéficie de la distribution sans payer ;
2. **KA Enterprise n'est JAMAIS caritatif** : ni la Fondation ni les donateurs ne financent l'IA d'entreprise — c'est l'inverse qui est vrai : **le B2B finance l'écosystème** ;
3. **La distinction MINSANTE** : le protocole institutionnel (impact, CNERSH, Chèque Santé) = Fondation · les **contrats de services** avec les hôpitaux/CHU (KA Enterprise) = Corporation, prestations commerciales facturées ;
4. **La compression HCV** vit dans la Ligne 3 (B2B opérateurs) — jamais mentionnée dans l'espace donateur, cohérent avec la stratégie phase 3 (prouver en santé, vendre aux telcos) ;
5. **La Ligne Compute ne se négocie pas avant la preuve** : la priorité MTN se limite à **ses propres datacenters** ; le reste du marché (datacenters indépendants, autres opérateurs) reste libre ; la trajectoire FPGA → ASIC → optique et sa PI restent à KA ; la Ligne 4 se finance par les revenus des Lignes 1-3.

## 2. Le modèle de fonctionnement — les flux

```
                         FLUX FINANCIERS (année 1)
┌──────────┐   dons + reçus 66 %   ┌────────────────┐
│ Donateurs │ ───────────────────► │ KA FONDATION   │
│ diaspora  │                      │ (Irlande/UE)   │
└──────────┘                      └───────┬────────┘
                                          │ convention de financement
                                          │ (publiée, auditée)
                                          ▼
┌──────────┐   fees 1 % + abonnements   ┌────────────────┐
│ Diaspora │ ─────────────────────────► │ KA CORPORATION │──► MTN MoMo
│ (UM)     │   (flux commercial UM)     │                │    (change 1-2 %)
└──────────┘                            └───────┬────────┘
                                          │ plateforme à prix coûtant
                                          ▼
                              🏥 SOINS — patients démunis (Fondation)
                              🏪 Réseau pharmacies / médecins (Corporation)
```

| Flux | De → À | Règle |
|---|---|---|
| Dons | Donateurs → **Fondation** | Reçus fiscaux, comptes publiés |
| Subvention de soins | **Fondation** → projets terrain | Jamais de R&D ; rapport d'impact par projet |
| Services plateforme | **Corporation** → Fondation | **Prix coûtant** (convention publiée, auditée) |
| UM | Diaspora → **Corporation** → MTN MoMo | Fees 1 % Corporation · change 1-2 % MTN |
| B2B (compression HCV) | Opérateurs → **Corporation** | 100 % commercial — la Fondation n'en voit rien |
| Marques | **Corporation** → Fondation | Licence gratuite d'usage dans le champ caritatif |

**Gouvernance croisée (anti-conflit) :**
- Le CA de la Corporation (3-5 membres) et le Conseil de la Fondation (5 membres : 2 bénévoles diaspora, 1 médecin, 1 financier, 1 représentant des bénéficiaires) ;
- **1 administrateur croisé** dans chaque organe (transparence, coordination) ;
- **Audit annuel** de la Fondation publié ; comptabilité de la Corporation certifiée ;
- Comité d'éthique commun (ad hoc pour les protocoles CNERSH).

## 7. Ce que ce modèle résout

- **Le conflit d'intérêts** : les donateurs financent des soins, jamais du marketing — c'est l'argument de confiance n°1 de la campagne donateur ;
- **L'image** : la Fondation camerounaise signe avec MINSANTE, la Corporation facture MTN — chaque entité parle à son public ;
- **La fiscalité** : reçus 66 % via le véhicule UE de la Fondation (Irlande) ;
- **Le moat** : la Corporation garde toute la PI et les contrats commerciaux (dont la compression HCV telecom) — la Fondation rend le modèle irréprochable, pas dépendant.
