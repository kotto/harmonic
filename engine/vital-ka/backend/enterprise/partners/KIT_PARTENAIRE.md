# 🤝 KIT PARTENAIRE — Devenir revendeur KA Enterprise

## Le programme en une page

Vous avez une relation de confiance avec des PME (cabinet comptable,
agence web, intégrateur, SSII, hébergeur régional). KA Enterprise est
l'IA de leurs données privées — et vous la revendez avec une commission
récurrente.

| | |
|---|---|
| **Votre commission** | **30 % du récurrent** sur les licences de vos clients (Starter 49 € → 14,70 €/mois · Business 149 € → 44,70 €/mois) |
| **Votre apport** | 20 % forfaitaire sur les options (migration, formation) |
| **Durée** | tant que le client est actif — récurrent, pas de plafond |
| **Suivi** | code partenaire (tracking automatique à la souscription) |
| **Vos outils** | kit de démo complet, script de vente, VPS de démo dédié, visio de formation 1 h |
| **Engagement** | aucun minimum, aucun exclusif — vous gardez vos clients |

## Ce que vous vendez (pitch 30 secondes)

> « Une IA qui répond uniquement sur les données de votre entreprise —
> clients, factures, procédures. Elle vous donne les chiffres, les tableaux
> Excel, les emails rédigés. Elle vous dit quand elle ne sait pas, au lieu
> d'inventer. Tout tourne sur votre VPS, vos données ne sortent pas de chez
> vous. À partir de 49 €/mois. Je vous montre en 15 minutes ? »

## Vos arguments différenciants (pour vos clients)

1. **Zéro hallucination contractuelle** : réponse ancrée + refus calibré.
2. **Données souveraines** : le VPS du client, jamais chez un tiers.
3. **Livrables** : Excel, documents, comptes-rendus — pas juste du chat.
4. **Prix** : 49 €/mois forfait, pas de coût par question, pas de GPU.
5. **Auto-apprentissage** : l'IA s'enrichit des questions réelles.

## La démo (kit fourni)

- VPS de démo : `python deploy_provider.py --ip <IP> --ssh-key …` (2 min)
- Script de vente : `python demo_kit/run_demo.py --onboard "Cabinet Test"
  admin@… --base http://IP:8767` — 15 minutes, arguments affichés
- Déroulé commercial : `demo_kit/SCRIPT_DEMO.md` (mot pour mot)
- Dataset réaliste : cabinet comptable (12 clients, factures, procédures)

## Vos cibles prioritaires (par ordre de rentabilité)

1. **Cabinets comptables & d'expertise** — prescripteurs naturels, données
   sensibles, documents en masse.
2. **Avocats / notaires** — confidentialité absolue, étanchéité par dossier.
3. **Cliniques & professions de santé** — conformité, protocoles.
4. **PME industrielles & de services** — procédures, opérateurs.

## Conditions et engagement

- **Code partenaire** attribué à la signature (7 jours).
- **Formation** : 1 h visio (kit de démo + script + objections) incluse.
- **SLA de votre côté** : support niveau 1 par vous (onboarding, facturation)
  ; niveau 2 par nous (produit) sous 24 h.
- **Exclusivité** : jamais exigée. **Transparence** : vos clients sont vos
  clients ; nous ne les démarchons pas.
- **Résiliation** : 30 jours, commissions acquises conservées.
