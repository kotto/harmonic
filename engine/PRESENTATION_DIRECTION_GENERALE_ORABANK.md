## SLIDE 1 — Le constat

# La santé en Afrique : 60% des paiements encore en espèces

**Un problème de circulation, pas de moyens**

```
┌──────────────────────────────────────────────────────────────────┐
│                                                                │
│  60%       des paiements de santé sont en cash                 │
│  80%       des Africains n'ont pas d'assurance santé           │
│  < 5%      des transactions de santé sont digitalisées         │
│  10 000+   décès évitables par faute de moyens de paiement     │
│                                                                │
│  La diaspora envoie 95 Mds $/an en Afrique                     │
│  → 0 moyen simple de payer les soins d'un proche à distance    │
│                                                                │
└──────────────────────────────────────────────────────────────────┘
```

**Le marché est immense, le besoin est urgent, la solution n'existe pas.**

---

## SLIDE 2 — La solution

# KARE : une monnaie de santé, pas une monnaie de spéculation

**L'Unité Médicale (UM) — 1 UM = 1 EUR = 655 FCFA**

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│   💚  Patient                                                       │
│       → Reçoit des UM de la diaspora, de la solidarité              │
│       → Ne peut les utiliser QUE pour se soigner                    │
│       → **Non convertible** → pas de sortie d'argent                │
│                                                                     │
│   🩺  Médecin / Pharmacien / Labo                                   │
│       → Reçoit des UM en paiement des soins                         │
│       → **Convertible en CFA** → avec traçabilité et plafonds       │
│                                                                     │
│   ✈️  Diaspora                                                      │
│       → Achète des UM par Mobile Money / carte                      │
│       → Les envoie instantanément à un proche                       │
│       → 0 frais pour le bénéficiaire                                │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

**L'argent de la santé reste dans la santé.**
