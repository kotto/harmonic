Le tableau périodique et les masses — par la refondation

Trois filtres emboîtés produisent la matière : le spectre d'entiers (2n², 2(2l+1)) → le tableau périodique (118/118 périodes, 7 gaz nobles) ; la surface de masse (Weizsäcker) → le pic de fer comme survivant (Ni-62, 0,12 %) ; et la famille T* = ΔE/(k_B·ln φ) → les températures dorées d'ionisation (24 instances, déposées, datées, falsifiables). Aucun paramètre dans la partie dérivée ; les coefficients empiriques sont documentés comme tels.

1 · L'architecture — trois filtres emboîtés

Spectre d'entiers → filtre atomique → filtre nucléaire → filtre thermique

La refondation lit la matière par l'élimination : les couches fermées (gaz nobles) survivent au filtre atomique (Madelung) ; les noyaux au fond de la vallée survivent au filtre nucléaire (surface de masse) ; et la température dorée est la signature thermique de chaque élément. Trois survivants — pas choisis, pas ajustés.

2 · Le tableau périodique — 118 éléments générés

118/118 périodes · 7 gaz nobles · 90/118 groupes (les 28 écarts = le bloc f)

Depuis les sous-couches (n, l) et la capacité 2(2l+1) — le spectre d'entiers (brique « comptage ») — et l'ordre de Madelung (n+l, n) — le filtre d'énergie minimale — la génération produit les 118 périodes exactement. Les 7 gaz nobles émergent des couches fermées. Les 28 écarts de groupe sont TOUS dans le bloc f (La–Yb, Ac–No) : Madelung naïf donne 6s²4fⁿ (groupe 2) ; le tableau réel place d¹ (5d¹6s², groupe 3). Les configurations qui survivent ne sont pas les plus simples — ce sont les plus stables. L'élimination, visible à l'intérieur même du tableau.

Commande : python generation_tableau_periodique.py — rapport JSON.

3 · Les masses — le pic de fer et la frontière lourde

8,5×10⁻⁵ sur les monoisotopiques · Ni-62 à 0,12 % · vallée lourde : frontière

Base : formule de Weizsäcker (coefficients empiriques documentés — les modèles « harmoniques » antérieurs 6π⁵/H_Z² sont réfutés par le protocole A1.3/A1.5).

  • Masses monoisotopiques (22 éléments) : erreur 8,5×10⁻⁵ ✅
  • Pic de BE/A : Ni-62, 8,783 MeV vs 8,794 réel (0,12 %) — affiné par les nombres magiques (2, 8, 20, 28, 50, 82, 126 — le spectre d'entiers) ✅
  • Vallée lourde (Z ≥ 78) : écart jusqu'à 45 unités de masse — exige les corrections de couches réelles (N=82, N=126) — ❌ frontière documentée, pas une revendication

Lecture : la surface de masse EST le filtre de stabilité — le pic de fer (Ni-62) est le survivant. La vallée lourde est le territoire du comptage (magique) — tracé, pas conquis. Commande : python calcul_masses_elements.py.
