Une constante émergente n'est pas une valeur mesurée : c'est une valeur calculée.

Démontrer que les constantes sont émergentes

Le protocole en 6 étapes : dérivation avec zéro paramètre, vérification à précision déclarée, test qui peut tuer l'émergence. L'état actuel : λ et cₙ démontrées · H, T*, α conditionnelles · Λ approchée (×1,4) · α=1/137 et masses en frontière déclarée.

La définition opératoire

Trois conditions

1 · DÉRIVATION : C = f(axiomes) — la chaîne contient ZÉRO paramètre libre
2 · VÉRIFICATION : la valeur calculée = la valeur mesurée (précision déclarée)
3 · FALSIFICATION : il existe un test qui peut TUER l'émergence

Sans la condition 3, ce n'est pas une démonstration — c'est un récit. Sans la condition 1, ce n'est pas une émergence — c'est une constante déguisée.

Le protocole

Six étapes

ÉTAPE 1 · ÉCRIRE la chaîne : axiomes → C (chaque étape explicite)
ÉTAPE 2 · COMPTER les paramètres libres (doit être 0)
ÉTAPE 3 · CALCULER C à la machine (aucun ajustement)
ÉTAPE 4 · COMPARER à la mesure (précision déclarée AVANT)
ÉTAPE 5 · PUBLIER le test qui peut tuer l'émergence
ÉTAPE 6 · DÉCLARER le statut : démontrée · partielle · approchée · frontière

L'étape 4 est cruciale : la précision est déclarée avant la comparaison — c'est le protocole des dépôts (E1bis, E3 v2).

L'arme anti-déguisement

Le test X1

La démonstration d'émergence doit prouver que C n'est pas une entrée déguisée — une constante injectée silencieusement puis « retrouvée ». Le test X1 est ce protocole :

Les constantes {φ, π, e, √2, √3, √5, e/π…} ont été TESTÉES comme coefficients :
· 0 correspondance spontanée sur 935 comparaisons (seuil 10⁻³)
· les 20 correspondances exactes sont TOUTES expliquées (T*, construction)
→ Le cadre ne déguise pas ses entrées — il les CALCULE.

La règle : toute constante proposée comme émergente doit passer le test de spontanéité — ses occurrences expliquées par la chaîne, pas par coïncidence.

En une phrase

Démontrer l'émergence d'une constante, c'est satisfaire trois conditions : la calculer avec zéro paramètre (dérivation), la retrouver à la précision déclarée (vérification), et publier le test qui peut la tuer (falsification). Deux constantes sont démontrées (λ, cₙ), trois sont conditionnelles (H, T*, α), une est approchée (Λ ×1,4), deux sont des frontières déclarées (α = 1/137, masses) — et la démonstration complète passe par les trois prédictions testables.
