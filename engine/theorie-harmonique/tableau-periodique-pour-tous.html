Le tableau périodique n'est pas une liste apprise par cœur — c'est un immeuble rempli selon une règle unique.

Le processus de remplissage du tableau périodique

118 éléments, 7 périodes de tailles 2-8-8-18-18-32-32, 7 gaz nobles — tout sort de simples nombres entiers et d'une règle de remplissage. Voici le processus, expliqué à tout le monde : les pièces de l'immeuble, la file d'attente, les étages pleins, et les 18 éléments prédits que personne n'a encore vus.

L'image de départ

Un immeuble à électrons

ÉTAGE 7 ── 32 places (2 + 14 + 10 + 6)
ÉTAGE 6 ── 32 places
ÉTAGE 5 ── 18 places
ÉTAGE 4 ── 18 places

Les étages sont les périodes du tableau — les lignes. Les tailles 2, 8, 8, 18, 18, 32, 32 sont les nombres d'éléments de chaque ligne.

2 + 8 + 8 + 18 + 18 + 32 + 32 = 118. Exactement les 118 éléments connus.

La grande question : pourquoi ces tailles-là ? Réponse : elles ne sont pas choisies — elles sont calculables à partir de simples nombres entiers.

Dans quel ordre remplit-on ?

La règle d'ascenseur (Madelung)

On remplit d'abord les pièces les moins chères en énergie : celles dont la somme (étage + forme) est la plus petite. À somme égale, on prend l'étage le plus bas.

L'image : une file d'attente devant l'immeuble. Chaque nouvel électron prend la première pièce libre dans cet ordre.

1s → 2s → 2p → 3s → 3p → 4s → 3d → 4p → 5s → 4d → 5p → 6s → 4f → 5d → 6p → 7s → 5f → 6d → 7p

Le point amusant : regardez le détour « 4s → 3d ». L'étage 4 se remplit avant que l'étage 3 ne soit fini ! C'est le célèbre « paradoxe » de Madelung — mais il découle simplement de la règle : la pièce 4s coûte moins cher que la pièce 3d. Le tableau périodique a exactement cette forme à cause de ce détour.

Les survivants

Les gaz nobles : les étages complets

Pourquoi l'hélium, le néon, l'argon… ne réagissent-ils presque avec rien ? Parce que ce sont les étages COMPLÈTEMENT remplis. Une fois la dernière pièce occupée (s²p⁶), l'immeuble est « fini » — les électrons n'ont envie de rien partager.

Le principe d'élimination (A1) lit cela directement : les configurations qui survivent sont celles qui ne « cherchent » rien. Les gaz nobles sont les survivants des couches fermées.

Z=2 Hélium (1s²) · Z=10 Néon (2s²2p⁶) · Z=18 Argon (3s²3p⁶) · Z=36 Krypton · Z=54 Xénon · Z=86 Radon · Z=118 Oganesson

7 sur 7 — vérifié par ordinateur. Les gaz nobles ne sont pas une liste à mémoriser : ce sont les étages pleins. L'élimination les a laissés survivre.

Les 28 écarts, expliqués honnêtement : ce sont exactement les 14 lanthanides et les 14 actinides. Ce n'est pas une erreur de placement — ces éléments sont au bon étage. C'est une différence de convention de numérotation : la règle des électrons de valence dit « groupe 2 », la convention IUPAC les regroupe en « colonne 3 » parce qu'ils se ressemblent tous chimiquement.

Les configurations « anomales » (Cr, Cu, Mo, Ag, Au…) : un électron saute d'une pièce à moitié pleine vers une pièce vide pour une stabilité plus grande (couches à moitié/entièrement remplies). La THU lit cela comme le filtre de stabilité qui tranche : les survivants ne sont pas toujours les plus simples — mais les plus stables.

La prédiction

Le bloc g — 18 éléments jamais vus

Si l'on prolonge la même règle au-delà de l'étage 7, la file continue : 8s → 5g → 6f → 7d → 8p…

La pièce g (l = 4) a une capacité : 2 × (2×4 + 1) = 18 places.

Prédiction : après Z=120, les électrons remplissent la pièce 5g — un nouveau bloc de 18 éléments (Z = 121 à 138) qui n'a jamais été observé. C'est une prédiction falsifiable : quand les éléments 119-120 puis 121+ seront synthétisés, leur chimie dira si la règle tient.

Ce que ça prouve — et ce que ça ne prouve pas

Les limites, dites clairement

✅ Ce que ce fait établit :
1. La forme du tableau (118 éléments, 7 périodes, 7 gaz nobles) est dérivable de simples entiers et d'une règle de remplissage
2. Les tailles des périodes sortent des capacités des sous-couches — zéro paramètre ajusté
3. Les gaz nobles émergent comme survivants des couches fermées (A1)
4. Le bloc g est une prédiction testable

⚠️ Ce que ce fait n'établit PAS :
1. La THU n'explique pas pourquoi les capacités sont 2, 6, 10, 14 — elle les prend de la mécanique quantique standard (les nombres quantiques). C'est la forme du tableau qui est dérivée, pas la mécanique quantique elle-même
2. La règle de Madelung est prise comme donnée — pas dérivée des axiomes (frontière ouverte)
3. Les 28 conventions de groupes et les configurations anomales sont décrites et lues par la théorie, pas prédites à l'avance
4. Le bloc g est une prédiction — elle doit attendre la synthèse des éléments
