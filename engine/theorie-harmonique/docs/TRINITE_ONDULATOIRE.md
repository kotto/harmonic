## 4. Pourquoi trois, et pas deux ou quatre ?

### Deux ne suffit pas

Avec seulement deux éléments (ex: espace et temps), il n'y a pas
de TIERS qui les relie. La ligne existe, mais il n'y a pas de
« point de vue » extérieur pour l'observer. Deux, c'est la
dualité (bien/mal, onde/particule, 0/1). C'est nécessaire mais
incomplet.

### Quatre est redondant

Avec quatre éléments, l'un est toujours une combinaison des trois
autres. La tétrade est le carré — stable mais statique. Elle ne
crée rien de nouveau.

### Trois est le minimum créateur

```
1 point  → rien à relier          (n=0, le vide)
2 points → UNE ligne              (n=2, la gravité, 1ère dimension)
3 points → UN triangle            (n=3, l'espace-temps, 3 dimensions)
           + le point de couplage
           = LA TRINITÉ
```

> **Trois est le plus petit nombre qui forme une figure FERMÉE.**
> **Le triangle est la plus petite structure COMPLÈTE.**
> **C'est pourquoi l'univers a 3 dimensions spatiales,**
> **et pourquoi la trinité apparaît dans toutes les traditions.**
