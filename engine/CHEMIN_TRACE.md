## 3. Pourquoi φ garantit la nouveauté

```
Soit φ₀ la phase initiale du cycle k.
Soit φ_{k+1} la phase initiale du cycle k+1.

φ_{k+1} = φ_k + 1/φ  (mod 2π)

Parce que 1/φ est IRRATIONNEL :
  φ_{k+1} ≠ φ_k  pour tout k.
  Aucun cycle n'a la MÊME phase initiale qu'un cycle précédent.

Parce que 1/φ est MAXIMALEMENT irrationnel :
  La séquence {φ_k} est la PLUS DENSE possible sur le cercle.
  → Aucun motif ne se répète.
  → L'univers explore TOUTES les possibilités, sans jamais boucler.
```
