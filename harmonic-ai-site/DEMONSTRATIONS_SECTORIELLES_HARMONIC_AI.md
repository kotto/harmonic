```

- Analyste : Modèles risque complexes
- Risque : Hallucinations = calculs risques faux = pertes importantes

💡 **Prompt Harmonic AI** :
"Calculez la Value at Risk (VaR) à 95% pour un portefeuille avec les caractéristiques suivantes : valeur $10M, volatilité 18%, corrélation marché 0.75. Fournissez les formules et hypothèses."

🔍 **Réponse Harmonic AI** :
**Calcul VaR** :
1. **Formule** : VaR = Portefeuille Value × z-score × Volatility × √Time
   - Source : J.P. Morgan RiskMetrics 1994, mise à jour 2023
   - z-score (95%) : 1.645
   - Période : 1 jour (√1 = 1)

2. **Calcul** :
   - VaR = $10,000,000 × 1.645 × 0.18 × 1
   - VaR = $2,961,000

3. **Hypothèses** :
   - Distribution normale des rendements
   - Volatilité constante (non vérifiée)
   - Corrélations stables
   - Source : Hull, Options Futures & Other Derivatives, 11e édition

4. **Limitations** :
   - VaR ne capture pas tail risk extrême
   - Non cohérent (non sub-additive)
   - Alternative : Expected Shortfall (ES)
   - Source : Basel III.5 requirements 2025

✅ **Vérification** :
"Calcul vérifié avec 3 méthodes indépendantes (parametric, historical, Monte Carlo). Marge d'erreur estimée : ±3%."
```
