Documentation API

L'API Harmonic AI fournit une génération d'IA déterministe avec des réponses vérifiables. Tous les endpoints garantissent même prompt ⇒ même sortie avec temperature=0.

URL de Base

https://api.harmonic.ai/v1

Authentification

Toutes les requêtes API nécessitent une clé API passée dans l'en-tête :

Authorization: Bearer VOTRE_CLÉ_API

Endpoint Generate

Générer des réponses d'IA déterministes avec mode vérifié optionnel.

Requête

POST /generate
Content-Type: application/json

{
"prompt": "Expliquez l'informatique quantique",
"max_tokens": 200,
"temperature": 0.0,
"verified_mode": true
}

Réponse

{
"response": "L'informatique quantique utilise des bits quantiques (qubits)...",
"response_id": "SHA256-4a7b9c8d2e1f0a9b8c7d6e5f4a3b2c1d0e9f8a7b6c5d4e3f2a1b0c9d8e7f6a5b4",
"verified": true,
"citations": [
{
"source": "Nature Physics, 2023",
"relevance": 0.95
}
],
"cache_hit": false,
"processing_time_ms": 245
}

Codes d'Erreur

Code Description
400 Paramètres de requête invalides
401 Clé API invalide ou manquante
429 Limite de débit dépassée
500 Erreur interne du serveur

Guide d'Intégration

Suivez ces étapes pour intégrer Harmonic AI dans vos applications.

Étape 1 : Obtenir les Identifiants API

  1. Créez un compte Harmonic AI
  2. Accédez à la section API dans votre tableau de bord
  3. Générez une nouvelle clé API
  4. Stockez la clé en sécurité (jamais dans le contrôle de version)

Étape 2 : Choisir la Méthode d'Intégration

Appels API Directs

Effectuez des requêtes HTTP directement vers nos endpoints REST.

Recommandé pour les implémentations personnalisées

Intégration SDK

Utilisez nos SDK officiels pour Python, JavaScript et Java.

Recommandé pour un développement plus rapide

Étape 3 : Implémenter le Mode Déterministe

Pour garantir des sorties déterministes, définissez toujours temperature=0.0. Combinez avec notre cache LRU pour des performances optimales.

# Exemple Python
import requests

api_key = "votre_clé_api"
headers = {"Authorization": f"Bearer {api_key}"}

payload = {
"prompt": "Votre question ici",
"max_tokens": 200,
"temperature": 0.0, # Critique pour le déterminisme
"verified_mode": True
}

response = requests.post(
"https://api.harmonic.ai/v1/generate",
json=payload,
headers=headers
)

Étape 4 : Gérer les Réponses

Vérifiez toujours le response_id pour l'auditabilité et vérifiez le statut verified pour les applications critiques.
