API Documentation

The Harmonic AI API provides deterministic AI generation with verifiable responses. All endpoints guarantee same prompt ⇒ same output when using temperature=0.

Base URL

https://api.harmonic.ai/v1

Authentication

All API requests require an API key passed in the header:

Authorization: Bearer YOUR_API_KEY

Generate Endpoint

Generate deterministic AI responses with optional verified mode.

Request

POST /generate
Content-Type: application/json

{
"prompt": "Explain quantum computing",
"max_tokens": 200,
"temperature": 0.0,
"verified_mode": true
}

Response

{
"response": "Quantum computing uses quantum bits (qubits)...",
"response_id": "SHA256-4a7b9c8d2e1f0a9b8c7d6e5f4a3b2c1d0e9f8a7b6c5d4e3f2a1b0c9d8e7f6a5b4",
"verified": true,
"citations": [
{
"source": "Nature Physics, 2023",
"relevance": 0.95
}
],
"cache_hit": false,
"processing_time_ms": 245
}

Error Codes

Code Description
400 Invalid request parameters
401 Invalid or missing API key
429 Rate limit exceeded
500 Internal server error

Integration Guide

Follow these steps to integrate Harmonic AI into your applications.

Step 1: Obtain API Credentials

  1. Register for a Harmonic AI account
  2. Navigate to the API section in your dashboard
  3. Generate a new API key
  4. Store the key securely (never commit to version control)

Step 2: Choose Integration Method

Direct API Calls

Make HTTP requests directly to our REST API endpoints.

Recommended for custom implementations

SDK Integration

Use our official SDKs for Python, JavaScript, and Java.

Recommended for faster development

Step 3: Implement Deterministic Mode

To guarantee deterministic outputs, always set temperature=0.0. Combine with our LRU cache for optimal performance.

# Python example
import requests

api_key = "your_api_key"
headers = {"Authorization": f"Bearer {api_key}"}

payload = {
"prompt": "Your question here",
"max_tokens": 200,
"temperature": 0.0, # Critical for determinism
"verified_mode": True
}

response = requests.post(
"https://api.harmonic.ai/v1/generate",
json=payload,
headers=headers
)

Step 4: Handle Responses

Always verify the response_id for auditability and check verified status for critical applications.
