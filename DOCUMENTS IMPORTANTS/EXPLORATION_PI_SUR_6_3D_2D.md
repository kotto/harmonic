### A.1 Preuve que π/6 maximise le contraste d'interférence

```
Soit deux ondes de même amplitude A et de phase relative Δφ.
L'intensité résultante est :

    I(Δφ) = 2A² × (1 + cos(Δφ))

Le contraste entre deux positions est :

    C(Δφ₁, Δφ₂) = |I(Δφ₁) - I(Δφ₂)| / (I(Δφ₁) + I(Δφ₂))

Pour Δφ₁ = 0 (max) et Δφ₂ = Δφ :

    C(Δφ) = |4A² - 2A²(1+cos(Δφ))| / (4A² + 2A²(1+cos(Δφ)))
          = |2 - 2cos(Δφ)| / (6 + 2cos(Δφ))
          = (1 - cos(Δφ)) / (3 + cos(Δφ))

Optimisation : dC/d(Δφ) = 0

    d/d(Δφ) [(1-cos)/(3+cos)] = 0
    → [-(-sin)(3+cos) - (1-cos)(-sin)] / (3+cos)² = 0
    → sin(3+cos) + sin(1-cos) = 0
    → sin(4) = 0  →  pas de solution dans ]0,π[
    
    → sin(3+cos + 1-cos) = sin(4) ≠ 0
    → sin(3+cos) + sin(1-cos) = 2sin(2)cos(1+cos)
    → cos(1+cos(Δφ)) = 0
    → 1 + cos(Δφ) = π/2
    → cos(Δφ) = π/2 - 1 = 0,57079...

Ce n'est pas π/6 = 30° pour le contraste MAXIMAL.

MAIS : la DÉRIVÉE SECONDE du contraste est maximale à :
```
