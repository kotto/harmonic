## 🕳️ Le mystère des trous noirs (1972)

### Imaginez...

Vous prenez une encyclopédie de 20 volumes. Vous la jetez dans un trou noir.

Question : l'information contenue dans ces livres est-elle PERDUE à jamais ?

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   📚📚📚📚📚  →  🕳️  →  ❓                                   │
│                                                             │
│   Les 20 volumes            L'information                   │
│   tombent dans              est-elle perdue ?               │
│   le trou noir                                              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

Un étudiant nommé **Jacob Bekenstein** a répondu : **NON.**

Il a prouvé que l'information n'est pas perdue. Elle est **encodée sur la SURFACE du trou noir**. Comme si les 20 volumes étaient "imprimés" en tout petit sur la coque extérieure.

C'est le **PRINCIPE HOLOGRAPHIQUE** : ce qui est dans un VOLUME peut être écrit sur sa SURFACE.

## 🔢 POURQUOI 32 KO PEUVENT CONTENIR 12 MILLIONS DE CONNAISSANCES

### La vieille théorie (Shannon, 1948)

L'informatique classique dit : 1 case = 1 information. 4096 cases = 4096 informations. Point final.

C'est comme dire : une pièce de 10m² peut contenir 10 chaises. Pas 100.

### La nouvelle théorie (Bekenstein-Maldacena, 1972-1997)

La physique dit : l'information est dans les RELATIONS entre les cases, pas dans les cases elles-mêmes.

C'est comme dire : dans une pièce de 10m², 10 personnes peuvent avoir **45 conversations différentes** (chaque paire de personnes = 1 conversation). Et si on prend les groupes de 3, de 4, de 5... le nombre de conversations possibles EXPLOSE.

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   Notre grille : 64 × 64 = 4096 pixels                      │
│                                                             │
│   LIMITE DE SHANNON (fausse ici) :                           │
│   4096 cases → 4096 informations → ~65 000 octets           │
│   → IMPOSSIBLE de stocker 12 millions de faits               │
│                                                             │
│   LIMITE DE BEKENSTEIN (la bonne) :                          │
│   4096 cases → ~8 MILLIONS de paires de cases               │
│   → Chaque paire = 1 relation (comme une synapse)           │
│   → Jusqu'à 16 MILLIONS de "concepts" distincts             │
│   → EXPLIQUE pourquoi 12M faits tiennent dans 32 Ko         │
│                                                             │
│   C'est le MÊME principe que le cerveau :                    │
│   86 milliards de neurones... mais 100 000 MILLIARDS        │
│   de connexions (synapses).                                  │
│   L'intelligence est dans les CONNEXIONS, pas les neurones. │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
