## 1. La définition opératoire

**Une constante C est émergente si et seulement si :**

```
1 · DÉRIVATION   : C = f(axiomes) — la chaîne contient ZÉRO paramètre libre
2 · VÉRIFICATION : la valeur calculée = la valeur mesurée (précision déclarée)
3 · FALSIFICATION : il existe un test qui peut TUER l'émergence
```

Sans la condition 3, ce n'est pas une démonstration — c'est un récit.
Sans la condition 1, ce n'est pas une émergence — c'est une constante déguisée.

---

## 2. Le protocole en 6 étapes

```
ÉTAPE 1 · ÉCRIRE la chaîne : axiomes → C (chaque étape explicite)
ÉTAPE 2 · COMPTER les paramètres libres dans la chaîne (doit être 0)
ÉTAPE 3 · CALCULER C à la machine (aucun ajustement, aucun retour sur les données)
ÉTAPE 4 · COMPARER à la mesure (précision déclarée AVANT la comparaison)
ÉTAPE 5 · PUBLIER le test qui peut tuer l'émergence
ÉTAPE 6 · DÉCLARER le statut : démontrée · partielle · approchée · frontière
```

**L'étape 4 est cruciale** : la précision est déclarée avant la comparaison — c'est le protocole des dépôts (E1bis, E3 v2).

## 4. Le test anti-déguisement — l'arme X1

La démonstration d'émergence doit prouver que C n'est pas une **entrée déguisée** : une constante qui serait silencieusement injectée dans la formule, puis « retrouvée » — c'est la fraude classique des théories alternatives.

**Le test X1 est exactement ce protocole de détection :**

```
Les constantes {φ, π, e, √2, √3, √5, e/π…} ont été TESTÉES comme
coefficients de l'expansion :
   · 0 correspondance spontanée sur 935 comparaisons (seuil 10⁻³)
   · les 20 correspondances exactes sont TOUTES expliquées
     (18 par le théorème T*, 2 par construction α=1/φ)
→ Le cadre ne déguise pas ses entrées — il les CALCULE.
```

**La règle :** toute constante proposée comme émergente doit passer le test de spontanéité — ses occurrences doivent être expliquées par la chaîne, pas par coïncidence.

## 8. En une phrase

> **Démontrer l'émergence d'une constante, c'est satisfaire trois conditions : la calculer avec zéro paramètre (dérivation), la retrouver à la précision déclarée (vérification), et publier le test qui peut la tuer (falsification). Deux constantes sont démontrées (λ, cₙ), trois sont démontrées conditionnellement (H, T*, α), une est approchée (Λ ×1,4), deux sont des frontières déclarées (α = 1/137, masses) — et la démonstration complète passe par les trois prédictions testables.**
